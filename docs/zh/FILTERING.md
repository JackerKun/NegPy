# 过滤胶片条

> **简体中文翻译** · 译自 [`docs/FILTERING.md`](../FILTERING.md) · 对应 NegPy v0.58.0 · 若有出入，以英文原文为准

左侧栏中的搜索框按文件名过滤胶片条。排序、热文件夹模式和"全部导出"都使用可见的（过滤后的）集合。

## 普通模式（默认）

输入任意文本。NegPy 将其与每个文件名匹配，不区分大小写。

| 输入 | 匹配 |
|-------|---------|
| `IMG` | `IMG_0001.cr2`、`img_test.NEF` |
| `.cr2` | 所有 `.cr2` 文件 |
| `_42` | 文件名中任意位置包含 `_42` 的文件 |

点击框中的 **×** 清除过滤。所有已加载文件立即恢复显示。

## 正则模式

点击搜索框旁的 **`.*`** 切换按钮。NegPy 使用 `re.IGNORECASE` 编译模式并用 `re.search` 匹配。使用 `^` 和 `$` 匹配完整文件名。

| 模式 | 匹配 |
|---------|---------|
| `^IMG_\d{4}` | `IMG_0001.cr2`、`IMG_0042.NEF` |
| `\.(cr2\|nef)$` | 仅 `.cr2` 或 `.nef` 文件 |
| `roll_\d+_scan` | 如 `roll_3_scan.tif` 的文件 |

无效正则（例如未闭合的 `[`）会将输入框边框变红并保留上一次的过滤结果。输入时不会有任何内容消失。

## 行为

- **选区跟随过滤。** NegPy 从多选集中移除隐藏文件。活动文件移动到第一个可见选区，若无匹配则清除。同步编辑不会触及不可见文件。
- **全部导出仅导出可见内容。** 过滤到一个子集，然后点击全部导出。只有该子集被写入。
- **热文件夹模式仍会接收新文件。** 不匹配当前过滤条件的新文件保持隐藏，直到你清除或放宽过滤。
- **排序顺序保持不变。** 过滤在排序之后应用，因此可见顺序遵循你的名称/日期和升序/降序选择。
- **过滤仅限当前会话。** NegPy 以空过滤启动。
