# 更新日志

> **简体中文翻译** · 译自 [`docs/CHANGELOG.md`](../CHANGELOG.md) · 对应 NegPy v0.58.0 · 若有出入，以英文原文为准

## 0.58.0

- 新增：**印相影调以摄影冲印文献为依据** — 默认印相包络、自动反差等级与自动密度已按公开发表的优选再现数据重新调校；两个测光表现在只读取画面中有纹理的部分，片边、天空和平整的墙面不再决定反差等级或曝光。**请重新调校你的自动反差等级与自动密度目标** — 依赖自动功能的现有帧，印相效果会有所不同。
- 新增：**暗部深度与高光保持** — "设置目标"中的两个可调项，自动确定印相两端的落点：最暗的有纹理色调被保持在最低印相密度，最亮的色调获得自动高光加深，从而保留层次而不是印成纸白。任一功能都可用 0 关闭。
- 新增：**低显存导出分块** — 偏好设置中的一个选项（性能），将分块导出的块尺寸减半并取消回读流水线，面向导出中途耗尽共享内存的集成显卡。@TobbyTravel
- 新增：**Windows 启动时回退到可写的数据文件夹** — 当默认数据文件夹被阻止时，对话框会提供 Local AppData 或让你选择其他文件夹；不会复制任何内容，选择会被记住。@hsnilsson
- 变更：**光学除尘重构** — 检测器以红外通道为基准进行了实测并重写：用局部噪声阈值取代绝对阈值，在全细节下进行最小值池化检测，并采用种子生长法，使标记覆盖整个斑点、发丝连成一条。它现在能找到远多于以往的红外可见缺陷；在纹理强烈的胶片上，为保护图像细节会放弃部分标记。
- 变更：**锐化在深暗部衰减** — 两种锐化方法都在趋向纸黑时降低增益，那里颗粒相对细节最粗。
- 变更：**启动、浏览与导出更快** — 首次渲染与窗口构建更快，切换文件不再拖住界面，分块导出、16 位 TIFF 编码以及红外/灰尘烘焙都快了数倍。全分辨率预览之后的导出会复用该预览的检测与修复结果。
- 变更：**界面文字更亮** — 所有文本颜色都调亮了一档，禁用文字调得最多；样式表现在从主题取色，而不是自带副本。
- 修复：**仅有源文件输入 ICC 时的可打印性读数** — 开启软打样的窄带扫描会丢失该读数并记录错误。
- 修复：**切换按钮不再绘制焦点框。**
- 修复：**名称相近的两个胶片或传感器配置** — "Portra 400" 与 "Portra-400" 解析到同一个文件，保存其中一个会毁掉另一个。@MohammedAlkindi
- 修复：**热文件夹开启时的批量进度** — 热文件夹开关打开时，手动"添加文件"或"添加文件夹"导入没有进度对话框。@MohammedAlkindi
- 修复：**导出元数据中的 GPS 坐标** — 取整后的秒与分现在会向分与度进位。@MohammedAlkindi
- 修复：**文件大小选择正确的单位** — 略低于阈值的大小曾显示为 "1024.0 KB"。@MohammedAlkindi
- 修复：**启动时不再闪现无父级的小窗** — 工具栏、扫描灯与分区帮助控件在显示前正确设置父级。@hsnilsson
- 修复：**三色拍摄可选的曝光间延迟** — 一些较旧的 USB/PTP 相机在红/绿/蓝拍摄之间需要停顿；默认仍为零。@matthoosier

## 0.57.0

- 新增：**去马赛克面板** — 在"校准"下分别为预览和导出选择 CFA 插值方式；列表根据你的 libraw 构建所支持的内容生成，"自动"保持原有行为。
- 新增：**导出选项卡上的软打样分区** — 打印机与纸张预设、渲染意图、黑点补偿、模拟相纸白与模拟墨黑、色域警告，以及显示器配置文件；打样配置文件跟随导出配置文件，也可单独设置，因此可以在导出网络 JPEG 的同时为一次打印打样。
- 新增：**分析中的可打印性与修复读数** — 打样配置文件无法打印的画面占比，以及每条修复途径（红外、灰尘、手绘）重写的扫描占比。
- 新增：**正片（反转片）上的去偏色** — 该滑块现在对正片生效，用于暗部/高光交越的褪色 E-6 原件；正片从 0 起步，负片从 0.5 起步。
- 新增：**扫描仪达到其原生逐轴分辨率** — 设备仅在 x 轴提供的 DPI 值现在可用，读取后对 y 轴向上重采样；红外拍摄仍拒绝需要重采样的 DPI。@dtrtuser
- 变更：**镜头畸变成为逐图像控制** — 从平场配置移到"对齐"中，与俯仰、摇摆并列，没有配置的设备也能使用；在 ±0.10 范围内以 0.001 的更细步长调整。
- 变更：**界面一致性梳理** — 统一的字体比例、可读的提示文字、各面板统一的控件家族与按钮宽度，对话框中的单选按钮与焦点环，以及每个对话框底栏唯一的 Enter 目标；平场校正基于共享面板布局重建，校准与平场校正的重置已接通。
- 修复：**三色三联组可靠组装** — 帧间一致性按密度而非线性电平评分，相差数挡的曝光不再被拒绝；恢复的会话会将其散落的文件归组，一次拍摄会把自己的三次曝光交给发现流程，因此没有细节的帧仍能堆叠。@seanharding
- 修复：**Plustek 多重曝光扫描对齐** — pyOpticfilm 更新至 1.3.3。@jboneng
- 修复：**热文件夹在 Windows 上不再重复导入已打开的文件** — 路径按原始字符串比较，分隔符或大小写不同就被当作新文件。@MohammedAlkindi
- 修复：**`path:` 搜索查询在 Windows 上可匹配** — 反斜杠在匹配器看到之前就被当作转义符剥掉，导致文档中的查询返回空结果。@MohammedAlkindi

## 0.56.0

- 新增：**单一的导出配置文件控件** — 色彩空间与已导入的 ICC 配置文件合并进一个下拉菜单，ICC 不再悄然覆盖看似生效的色彩空间选择；"导入 ICC"将配置文件复制到 `~/NegPy/icc` 而无需重启，"与源文件相同"会标明其解析到的色彩空间，软打样及其警告移到它所描述的配置文件旁边。
- 新增：**TIFF、PNG 与 JPEG 导出选项** — 位深（8/16，用于 TIFF、PNG 和 JXL）、TIFF 压缩（未压缩/LZW/ZIP）、PNG 压缩（0-9）与 JPEG 渐进式；JPEG 优化始终开启。RGB PNG 现在默认以 16 位导出。
- 变更：**Plustek 后端更新至 pyOpticfilm 1.3。** @jboneng
- 修复：**平台扫描仪在扫描前切换到透扫源** — 平台+TPU 设备此前以反射模式、关灯执行每次胶片扫描，并按平台区域探测几何信息，导致裁剪与请求的 DPI 出错。@dtrtuser
- 修复：**带输入 ICC 的正片不再二次校正原色** — 生效的输入 ICC 会替换 raw 内嵌的相机矩阵，而不是叠加其上，与负片和窄带一致。@thetalkingdrum
- 修复：**3 色 CFA 传感器上线性输出的白平衡** — 缺失的第二个绿色乘数（X-Trans 及类似传感器）使红蓝增益翻倍，导出偏品红。@thetalkingdrum
- 修复：**HQ 预览不再在集成显卡上崩溃** — 大尺寸扫描此前不设大小预算就交给 GPU；集成显卡现在有保守的上限，并以降采样加状态消息的方式处理。@TobbyTravel
- 修复：**实时取景弹窗中 Enter 保持在"扫描"上** — 按一次"重拍"后，Enter 会一直重拍。@TobbyTravel
- 修复：**"复制设置 + 边界"会粘贴其边界** — 逐帧的下限、上限与锁定状态此前到不了目标帧，粘贴的边界字段还会清掉目标自己的；粘贴选择器现在将它们列为"归一化边界"。

## 0.55.0

- 新增：**通过 nkscan 扫描 Nikon Coolscan** — 直接驱动 Coolscan 而不再经过 SANE：一次行程在胶片上量出帧矩形、原生红外通道、原生退片以及驱动自带的 "ICE" 除尘，采样数、超精细、胶片类型与画幅规格控件按设备上报的能力显示。
- 新增：**OpticFilm 8100 V2 支持** — 扫描选项卡不再固定为 8200i SE；控件跟随各设备，两者都支持多重曝光，8100 V2 没有红外通道。@TobbyTravel
- 变更：**GPU 帧与分块导出减少主机端工作** — 测光表复用其预滤波网格而不再重新分区，没有边框要绘制时跳过相纸缓冲区。导出字节不变。
- 变更：**Plustek 扫描选项卡隐藏 pyopticfilm 后端不使用的控件。** @jboneng
- 修复：**相机连接不再因未填充的 gphoto2 控件而段错误** — 控件返回 NULL 值会导致应用崩溃。@fivedots
- 修复：**导出标注绝对分辨率** — TIFF 与 PNG 在"预览"中显示为 1 DPI，在 Photoshop 中回退为 72；现在每种格式都标注其长边所对应的 DPI，两条元数据重写路径都会带上它。@Icodextrin
- 修复：**线性输出不再在相机 DNG 上崩溃** — 一个陈旧的早期分支还会跳过 RGB 三联组、平场、传感器校正与白平衡。@Icodextrin
- 修复：**导出时剥离源相机的陈旧 EXIF** — 相机自身的 ColorSpace 标签及其相对于源文件的预览指针与文件真实的颜色标签矛盾，使严格的读取器认为导出文件无标签并拒绝预览。@thetalkingdrum
- 修复：**批量分析测量组装后的合成帧** — RGB 三联组或 HDR 合并此前只按单次曝光测量，导致其他通道反转为黑色，留下整卷纯红。@seanharding
- 修复：**相机扫描保持其识别探测赢得的 PTP 占用** — 释放占用会让 macOS 的相机守护进程接管接口数分钟，下一次实时取景或扫描因此被拒绝；瞬时的打开失败现在会重试而不是上报。@light-sntchr
- 修复：**画布 HUD 不再落后一次编辑** — 由配置绘制的胶囊（如导出色彩空间）此前要到下一次记录历史的编辑才更新。@seanharding
- 修复：**胶片条会说明是筛选而非加载失败使其为空** — 持久化的接触印相筛选若无匹配，会在满额帧数下留下空白胶片条；计数现在显示"0 / 36 帧 · 保留帧筛选"。@seanharding
- 修复：**H&D 图表不再在悬停时改变大小** — 探针行随更高的回退字体变高，挤占了图表的像素。

## 0.54.0

- 新增：**元数据预设** — 将任意一组元数据字段保存为命名预设，并从元数据面板应用；器材预设被其取代并自动转换，预设的值可在器材库中编辑。@Icodextrin
- 新增：**冲洗工艺与扫描配置库** — 已保存的配方（显影液、稀释比、迫冲/迫减、时间、温度）与扫描配置和相机、镜头、胶片并列；新字段进入 XMP、EXIF、元数据预览、文件名模板，并可作为 `devtime:`、`temp:` 与 `dilution:` 搜索。@Icodextrin
- 新增：**偏好设置对话框** — 应用全局设置集中一处（⋯ 菜单、Ctrl+, 或 macOS 应用菜单），分三个分区：界面、性能、会话与存储；九个 `override.toml` 键获得界面入口，被文件锁定的键会灰显其行并说明原因。
- 变更：**窄带拍摄模式更名** — "窄带扫描仪"、"三色"与"单次窄带"在界面与文档中取代 "RGB Scan"、"true RGB scan" 与 "Trichrome Calibration"。@thetalkingdrum
- 变更：**无模态窗口在 macOS 上保持在主窗口之上** — 导出进度窗口、串扰与曝光目标编辑器以及 Scanlight 窗口不再可能被压住。@seanharding
- 修复：**快捷键标签使用平台自身的记法** — macOS 菜单、工具提示与快捷键列表显示 ⌘C 而非 Ctrl+C，重新绑定的操作显示自己的按键而非默认按键。@seanharding
- 修复：**1:1 缩放不再放大预览** — 布局阶段会拉伸低于渲染尺寸解码的预览，100% 时并非一个扫描像素对应一个设备像素；裁剪帧与调高的 `preview_render_size` 受影响最重。@seanharding
- 修复：**三色曝光以中性白平衡解码** — 三个互不相关的拍摄时增益会给组装后的图像染色；三联组现在锁定 Linear RAW，反正它在那里不起作用。@thetalkingdrum
- 修复：**相机白平衡绝不折叠进窄带拍摄矩阵** — 预览底片、CPU 正片传输阶段与 GPU 着色器遵循同一规则。@thetalkingdrum
- 修复：**三色与单次窄带下"应用白平衡"灰显** — 窄带拍摄没有供拍摄时增益描述的宽带场景，线性输出烘焙因此无效。@thetalkingdrum

## 0.53.0

- 新增：**拍摄日期与地点** — 元数据面板中一张卡片，记录这一帧何时何地拍摄，带地图选点；可作为 `shot:` 与 `place:` 搜索。
- 新增：**预览底片** — 查看载入时的底片原样，未反转、未调色，以便在任何编辑前判断曝光或偏色；带色彩管理，橙色罩显示正确，预览期间密度直方图拆分为 R/G/B 与明度。@seanharding @thetalkingdrum
- 新增：**NegPy 获得 macOS 菜单栏** — "窗口"（最小化、缩放、关闭、窗口列表）与"帮助"（导览、快捷键、指南、检查更新、报告问题）。@seanharding
- 新增：**自选工具栏内容** — 拖动重排工具栏与收藏选择器，外加"编辑工具栏…"入口。
- 新增：**调整蒙版时其染色让位** — 加深、羽化与反差等级滑块不再透过染色叠加来判断；重叠的蒙版也会淡出。@Icodextrin
- 新增：**预览分辨率可配置** — `override.toml` 中 `[performance]` 下的 `preview_render_size` 设定交互预览的长边，介于 1600 px 默认值与完整 HQ 解码之间。
- 新增：**单次拍摄扫描预览** — 面向没有电动输片的扫描仪（Plustek 及类似设备），在完整扫描前提供一个轻量的预览与裁剪对话框。@cymbal221
- 变更：**导出与预览性能** — 批量导出在多个文件间重叠解码、渲染与编码，而不再严格顺序执行；工艺与传感器面板上的滑块拖动以及其他最坏情况的交互，不再付出稳定帧的成本。
- 变更：**画布缩放读取真实扫描像素** — 100% 现在在所有模式下都意味着一个扫描像素对应一个屏幕像素，HUD 胶囊会在 100% 显示的是放大的预览时给出标记。@seanharding
- 变更：**"保存编辑"操作移除** — 编辑已在每次更改时自动保存，显式命令多余。@seanharding
- 修复：**自动裁剪与批量自动裁剪修复七种边缘情况** — 深色主体、批量运行中的纵向帧、真黑暗部的正片、RGB 三联组以及没有可检测扫描床的胶卷，现在都能正确裁剪。@seanharding
- 修复：**导出四舍五入到最近的电平而非截断** — 每次导出以及画布本身此前都暗了最多半个电平。@seanharding
- 修复：**RGB 三联组无论文件名顺序都能正确归组** — 拍摄按拍摄顺序与场景内容归组和校验，而非文件名排序；一个组装不出任何内容的文件夹现在会说明原因。@seanharding
- 修复：**矩阵/TRC 输入 ICC 配置文件不再重复应用其色调曲线** — 旁路闸门从未触发；原色变换现在对 D50、D60 与 D65 原生配置文件都能正确构建并应用。@thetalkingdrum
- 修复：**ETTR 溢出判断不再信任通用传感器白电平** — 相机扫描校准使用相机公布的 ADC 上限而非其校准值，使溢出的通道读起来干净。@light-sntchr
- 修复：**拼接或 HDR 合并在切换文件夹后保留** — 合成成员关系现在独立于打开文件列表存储。@seanharding
- 修复：**元数据带入每种导出格式** — JPEG XL 与 WebP 此前丢弃所有字段；NegPy 写入的标点现在能在 EXIF 的 7 位限制下保留，JPEG XL 源文件自身的元数据也能正确读取。@Icodextrin
- 修复：**线性输出的三联组合并在过冲前被钳制** — 对齐变换的振铃可能在 float32 解码路径中把值推过 1.0 而未被捕获。
- 修复：**Linux 应用图标正确解析** — 遵循 AppImage 图标主题规范，并修复 Wayland 合成器下的任务栏图标。@kinnajowa
- 修复：**EXIF 解析不再运行于 `finally` 块内** — 格式错误的块会静默返回空元数据，而不是暴露真正的错误。@MohammedAlkindi
- 修复：**红外 TIFF 附属文件的描述不再携带源文件名。** @MohammedAlkindi

## 0.52.0

- 新增：**对比度蒙版** — 色调面板中的暗房模糊蒙版：一张模糊的低伽马夹层，压缩或展开整体范围，同时让精细细节透过。两个方向都可用，其作用范围在 H&D 图表上绘制为紫色条带。
- 新增：**俯仰与摇摆** — 以放大机尺板运动的方式做透视校正：俯仰拉直汇聚的垂直线，摇摆拉直汇聚的水平线。在此之前没有任何功能能移动汇聚线。
- 新增：**取消二联片分割** — 在胶片条中右键点击半格分割的扫描，即可还原为一个普通帧。破坏性操作且有确认；两半的编辑、撤销历史与工作样张都会消失。

- **自动密度**（新，默认开启）— 逐帧测量并设定合理的亮度，过曝或欠曝的底片无需手动微调即可用。它做*部分*校正，刻意压暗（低调）或提亮（高调）的拍摄保留其氛围，而不是被压平成中性灰。
- **自动反差等级**（新，默认开启）— 温和地为每个场景选择合适的对比度：平淡场景得到一点提升，有冲劲的场景保持冲劲，但不会被推向刺眼的极端。与自动密度一起，目标是结果即刻顺眼，同时仍易于微调。
- **反差等级现在使用 ISO R 标度** — 对比度按摄影用 ISO R 相纸反差等级标度设定（R180 极软 … R110 ≈ 经典 2 号 … R50 极硬），取代旧的 0–5 数字，曲线的 10–90% 跨度因此映射到真实的相纸曝光范围。旧的已保存 0–5 等级自动迁移（R = 150 − 20·G），保持已有编辑的观感。
- **关闭自动辅助后，转换诚实地跟随你的底片** — 致密 / 过曝的底片出来又密又硬，薄 / 平的底片出来平淡。没有任何东西被归一化抹平，印品完全反映该帧的曝光与显影。当你想让转换*展示你的摄影*而不是把它抹平时，关掉这些开关 — 这是审读自己曝光与显影的有用方式。
- **去偏色**（新，默认开启）— 自动中和底片留在印相中的偏色。它平衡每个颜色层，让灰色从深暗部一路到高光都读作中性，而不只在中间调 — 这是中间调白平衡（C-41）之后暗部或高光跑色的常见原因。
- **对比度提升**（新，默认关闭）— 基于偏好色调再现（Bartleson-Breneman）、围绕相纸白的温和对比提升：在普通房间观看的印品想要比 1:1 再现略多的中间调对比，因此它把中间调略微压暗并增加冲劲。
- **眩光**（新，默认关闭）— 暗房风格的罩雾眩光底限，温和抬起最深的黑、软化趾部，获得更胶片感的观感，同时相纸白保持固定。
- **自动裁剪重做**：更稳健的胶片边缘检测，几何侧栏新增**自动裁剪模式**选择器 — *仅图像*裁到曝光图像区域（默认），*胶片边缘*裁到完整胶片范围、保留片边/齿孔。检测在不同胶片与边框类型上应更可靠。
- **自定义串扰矩阵**：Lab **串扰**控件（由*分离度*更名）现在有配置下拉框。把你自己的 `.toml` 校准矩阵放进 `NegPy/crosstalk` 文件夹（首次运行播种一套起始矩阵），按胶片或扫描仪选用；内置矩阵仍作为*默认*可用。格式与如何向内置矩阵库贡献见 `docs/CROSSTALK.md`。
- 修复：**ICC 颜色管理现在在导出时正确应用** — 屏幕预览现在经工作空间 → sRGB 显示 LUT 做颜色管理，所见与导出文件一致。
- **ICC 移入导出面板**：专门的 **ICC** 分区持有明确的**输入**与**输出**选择器。输出选择器列出目标颜色空间与自定义 ICC 配置（与颜色空间条目重复的内置配置被隐藏）。输出选择同时驱动预览与导出文件（所见即所得 — 没有单独的应用开关）：预览直接显示输出空间，与非颜色管理查看器中看到的文件一致，导出转换到并嵌入同一配置。输入 ICC 校正源。右侧控件面板中独立的 ICC 分区已移除。
- **可隐藏的侧面板**：左侧会话面板与右侧控件面板现在可以折叠，获得专注的纯画布视图。新的开关按钮位于底部工具栏外侧边缘（及 `Ctrl+[` / `Ctrl+]` 快捷键）— 按钮反映每个面板的当前状态，隐藏/显示状态跨重启记住。
- 修复：**颜色调整现在使用正确的工作颜色空间** — 饱和度、自然饱和度、彩度降噪与分离色调计算其 CIELAB 时不再转换到 sRGB，颜色 — 尤其是绿色与青色 — 的偏移更准确、更可预测。中性灰不受影响。
- 修复：源 EXIF 带有越界标签时导出不再丢弃元数据。
- 修复：**批量分析**现在遵循文件浏览器筛选 — 筛选生效时只分析可见文件，与批量导出的行为一致（而不是总是对文件夹中的每个文件运行）。(#237)
