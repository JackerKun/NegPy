# 自定义串扰矩阵

> **简体中文翻译** · 译自 [`docs/CROSSTALK.md`](../CROSSTALK.md) · 对应 NegPy v0.58.0 · 若有出入，以英文原文为准

校准侧边栏中的**串扰**控件执行通道解混校正。NegPy 内置一个矩阵（**Generic C41**）。你可以放入自己的矩阵 — 针对你的胶片*和你的扫描设备*校准 — 而无需改动任何代码。

---

## 矩阵适用于哪种胶片

一个矩阵描述一种染料组，而彩色负片与正片（反转片）并不共用同一种。因此每个配置都声明其胶片工艺：

```toml
process = "Transparency"    # or "Color Negative" (the default when the key is absent)
```

下拉菜单只提供与当前处理胶片匹配的矩阵，渲染也以同一值为准入门槛。工艺不匹配的配置会退化为单位矩阵，而不是混入错误的校正。在此键出现之前写入的所有配置都是彩色负片胶片，这就是默认值为 `Color Negative` 的原因。在模式重命名（`C41`、`B&W`、`E-6`）之前写入的文件仍可加载。

NegPy 目前不随附任何正片（反转片）矩阵。在正片上，矩阵下拉菜单初始为空，且它与强度滑块均被禁用。编辑器按钮仍然可用：打开它，按 **+** 新建矩阵，新矩阵会按你当前所处的工艺创建。编辑器的**工艺**控件会在你保存的任何配置上设置该值，因此之后你可以选中为幻灯片设备构建的矩阵。只有在黑白负片下串扰才完全隐藏 — 它只有一种乳剂，没有可解混的内容。

> **反转片的解读方式不同。**在负片上，染料的有害吸收是需要在反转前去除的误差，因此解混使渲染结果*趋向*真实场景。而正片（反转片）本身**就是**成品图像。你在看片台上看到的画面已经包含这些吸收，因此解混会使它*偏离*幻灯片自身的外观，趋向其背后的染料量图像。在正片（反转片）模式下，请把串扰当作一种色彩分离控制，而非还原真实的校正；当你想匹配幻灯片本身的效果时，请将强度保持为 0。

## 它的作用

彩色负片的三个染料层在光谱上并不纯净。青、品红、黄染料各自都会向本不应影响的通道渗漏少量密度，导致颜色浑浊、分离度低。串扰校正对通道进行解混：在归一化与印相曲线*之前*，将逐像素的**底片密度**向量乘以一个 3×3 矩阵。矩阵正是在这个域中推导的，因为染料的二次吸收相对底片染料密度是线性的。

**染料并不是唯一成因。**你的光源光谱与传感器的色彩滤镜通带同样会混合通道。宽谱或形状特殊的光源在偏离各染料峰值处采样，并带出邻近染料的响应；相机的色彩滤镜也存在重叠。在密度域中，三种成因都表现为同一类误差 — 线性混合 — 这就是一个 3×3 矩阵能把它们一并吸收的原因，也是同一种胶片在不同设备上可能需要不同矩阵的原因。

因此，请把矩阵理解为**整套扫描设备**的属性，而不是某种胶片的属性。由数据表推导的配置只描述染料。真正能让*你的*扫描出彩的，是你在自己的光源和相机上调校出来的那一个。

同一面板中还有两个相关控件，它们*不能*互相替代。**传感器**矩阵在线性采集中校正相机。**色相微调**针对特殊的光源光谱旋转色相。参见 [USER_GUIDE.md](USER_GUIDE.md) §4.1。

> ### 内置矩阵究竟是什么
>
> 每个随附配置都是**从公开发布的光谱染料密度规格表上读出的，而不是在扫描上实测的**，因此每个名称里都带有 *(approx)*。在信任它们之前，有两点值得了解：
>
> - 它们只建模**染料本身**。只有当你的采集能干净地读取每个染料波段时，这才是完整的校正：**窄带扫描仪**（Coolscan 的单色传感器每次读取一个 LED，完全干净；Pakon 的三线阵列接近，但有轻微残余渗漏）、**三色**采集，或已应用**单次窄带校准**的单次窄带设备。在宽带光源加拜耳传感器下，你的光源与 CFA 会叠加数据表毫不知情的混合，仅描述染料的矩阵无法涵盖它。
> - 消费级数据表通常只发布一条*整体的*中间调中性曲线，而不是分离的 C/M/Y 曲线，因此即便是染料部分，也是从图表上目测读出的估计值。
>
> 对窄带设备而言，它们仍然是远好于单位矩阵的起点。只是不要指望某个内置胶片名称就是你扫描仪的“那个”校正。你自己调校的矩阵才是更可信的对象。内置矩阵是只读的；用**创建可编辑副本**从它开始。

数学上，对原始解码负片的每个像素：

```
density      = -log10(rgb_negative)
density_out  = M · density
```

`M` 是你的 3×3 矩阵。**串扰**滑块（0–1）将其与单位矩阵混合，并对结果按行归一化，因此 `0` 为关闭，`1` 为完整矩阵：

```
M_applied = I · (1 - strength) + M · strength
M_applied = M_applied / row_sums(M_applied)        # each row normalized to sum 1
```

由于每一行都重新归一化为总和 1，均匀的灰色仍保持灰色。矩阵只是在通道之间重新分配颜色*差异*。

## 解读矩阵

矩阵为行主序。**行是输出通道**，**列是输入通道**：

|            | in R   | in G   | in B   |
| :--------- | :----- | :----- | :----- |
| **out R**  | 1.00   | -0.05  | -0.02  |
| **out G**  | -0.04  | 1.00   | -0.08  |
| **out B**  | -0.01  | -0.10  | 1.00   |

- **对角线**保持在 `1.0` 附近，因此每个通道保留自身的密度。
- **非对角**项通常较小且为负。它们减去一层染料渗漏到另一层的污染。
- 让每行的总和保持在 `1.0` 附近。由于行会被归一化，较大的偏差也能工作，但会让效果更难推断。

## 文件格式（TOML）

将 `.toml` 文件放入你的用户文件夹：

```
<Documents>/NegPy/crosstalk/
```

内置矩阵库（仓库中的 `crosstalk/`）由应用直接读取，不会复制到这里，因此这些配置会与你的配置一起留在下拉菜单中，并随每次发布更新。同名时，内置名称优先于用户文件。每个文件是一个矩阵：

```toml
# my_film.toml
name = "Gold 200 + Spectracolor"   # optional display name; falls back to the filename
type = "tuned"                     # optional provenance; groups it in the dropdown
matrix = [                         # 3x3, row-major (out R/G/B × in R/G/B)
  [ 1.00, -0.05, -0.02],
  [-0.04,  1.00, -0.08],
  [-0.01, -0.10,  1.00],
]
```

- `matrix` 为**必填**：恰好 3 行、每行 3 个数字。
- `name` 为**可选**。缺省时，下拉菜单显示文件名（不含 `.toml`）。
- `type` 为**可选**。它说明*这些数字从何而来*，而这决定了可信程度。下拉菜单按类型将配置归入相应标题的分组：

  | `type` | 下拉菜单分组 | 含义 |
  | :--- | :--- | :--- |
  | `measured` | 实测 | 针对已知参照物的真实扫描拟合得到。 |
  | `tuned` | 在设备上调试 | 在真实画面上凭肉眼调校。编辑器保存的就是此类型。 |
  | `specsheet-based` | 来自规格表（近似） | 从公开发布的染料密度曲线读出。所有内置配置均属此类。 |
  | 其他值或缺省 | 其他 | 仍可加载并工作，只是不声明来源。 |

- NegPy 会静默跳过格式错误的文件（形状不对、非数字、TOML 无效）。
- 名称 `Generic C41` 为内置矩阵保留，重复使用将被忽略。

选中矩阵时，NegPy 会**将其固化进该条编辑记录**，因此即使你之后移动或删除该文件，已保存的编辑与预设仍可复现。

## 使用方法

1. 将你的 `.toml` 放入 `<Documents>/NegPy/crosstalk/`。
2. 打开**校准**侧边栏，在串扰分区下找到**串扰下拉菜单**。新文件会在面板下次同步时出现，例如切换照片时。如果看不到，请重启应用。
3. 选择你的配置，并将**强度**调到 0 以上以应用。
4. 选择 **Generic C41** 可回到内置矩阵。

### 自行调校矩阵（简版）

你不需要光谱数据或分光光度计，也能得到比 *Generic C41* 更好的矩阵，而且只有你自己能测量你自己的设备。推荐的循环：

1. 选一帧你清楚其真实颜色的画面：植被、天空、灰卡、皮肤。
2. 从 **Generic C41** 开始，提高**强度**，直到颜色分离但尚未变得俗艳。对许多设备而言，仅此一步就是全部收益。
3. 仍然以某种特定方式出错？打开矩阵编辑器，点击**创建可编辑副本**，微调出问题的那对通道的非对角项。绿色渗入红色对应 `out R / in G`。一次只调一项，小步前进。`0.02` 就肉眼可见。
4. 以**组合**命名保存，例如 `Gold 200 + Spectracolor`，而不只是胶片名。重新运行**批量分析**，并在第二帧上验证后再信任它。

如果色相是被旋转而非变浑浊 — 每种颜色都朝同一方向偏转、中性色却正常 — 那是光源光谱问题。**色相微调**是更省事的解决办法，而矩阵会与它相互对抗。浑浊、低分离度的颜色才是串扰的典型特征。

### 在应用中编辑矩阵

下拉菜单旁的**滑块图标**可打开**矩阵编辑器**，你无需手动编辑 TOML：

- 浏览所有配置。内置矩阵与 **Generic C41** 显示锁形图标，为**只读**。你自己的配置可编辑。
- 拖动非对角网格滑块（`out R/G/B` × `in R/G/B`），预览会实时更新。对角线是固定的，因为矩阵在应用时会按行归一化，使对角线变得多余。只有六个混合项可编辑。**预览强度**滑块仅控制此处的预览。要应用矩阵，请使用侧边栏的**强度**滑块。
- **创建可编辑副本**将所选的锁定矩阵克隆为一个可编辑配置。
- **保存**将配置以 `.toml` 形式写入 `<Documents>/NegPy/crosstalk/` — 与读取配置相同的文件夹 — 因此它会出现在下拉菜单中。
- **应用并关闭**保留你正在预览的结果。**取消**则回退。

> 串扰是一种色彩操作，在黑白负片模式下隐藏。它会改变归一化测光读到的内容，因此在更改配置或强度之后，请重新运行**批量分析**（并重新保存锁定边界）。

## 贡献矩阵

为你的设备调好了一个？请把它发给我们。把你的 `.toml` 添加到仓库的 [`crosstalk/`](../../crosstalk/) 文件夹并发起 PR。内置矩阵会在下一次发布时提供给所有用户。参见 [`crosstalk/README.md`](../../crosstalk/README.md)。

在配置名称和 PR 中说明它来自哪套设备：胶片、光源，以及相机或扫描仪。没有人能从数据表推导出你的光源和传感器，因此一个针对常见组合、经过实战测量的配置，对其他人来说比任何理论都更有用。光源面板也会停产，因此为人们手中已有的设备保留配置是值得的。
