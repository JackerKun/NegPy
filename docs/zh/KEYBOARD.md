# 键盘快捷键

> **简体中文翻译** · 译自 [`docs/KEYBOARD.md`](../KEYBOARD.md) · 对应 NegPy v0.58.0 · 若有出入，以英文原文为准

每个快捷键（包括滑块步长）都可以在应用内更改。按 `?` 打开快捷键浮层，然后点击**自定义**。滑块快捷键以合并行显示（例如**密度 ↑/↓**），并带有**步长**列。默认值列在下方。

滑块快捷键会在画布 HUD 中报告其新值，因此你可以把某个控件留在隐藏的选项卡上，仍能读到你设置的数值。

被当前模式或某个锁定停用的控件不会随键盘移动。黑白帧上的色温就是一个例子：快捷键不改变任何东西，HUD 显示控件名称而不是数值。位于其他选项卡、折叠分区或已关闭面板之后的控件仍然有效。

此列表中的 `Ctrl` 在 macOS 上是 `⌘`。应用按你所在平台的写法书写每个按键，因此菜单、工具提示和浮层在 macOS 上显示 `⇧⌘C`，在其他平台显示 `Ctrl + Shift + C`。

小键盘按键可以与数字行分开绑定（例如 `Num+9` 和 `9`）。小键盘数字需要开启 Num Lock。

## 导航
| 按键 | 操作 |
|-----|--------|
| `左方向键` | 上一张图像 |
| `右方向键` | 下一张图像 |

## 挑片
| 按键 | 操作 |
|-----|--------|
| `K` | 将帧标记为保留 |
| `Shift + X` | 淘汰帧（批量导出与附属文件写入会跳过） |

## 图像调整（高速）
| 按键 | 操作 |
|-----|--------|
| `Q` / `A` | 增大 / 减小**密度**（默认步长 0.01） |
| `W` / `S` | 增大 / 减小**反差等级**（默认步长 10 ISO-R） |
| `E` / `D` | 增大 / 减小**品红**（默认步长 0.01） |
| `R` / `F` | 增大 / 减小**黄**（默认步长 0.01） |
| `X` / `Z` | 增大 / 减小**裁剪偏移**（默认步长 1 px） |

## 工具
| 按键 | 操作 |
|-----|--------|
| `Shift + W` | 切换白平衡吸管 |
| `Shift + C` | 切换手动裁剪工具 |
| `Shift + D` | 切换修复工具（灰尘斑点拾取） |
| `Shift + S` | 切换划痕工具 |
| `Shift + K` | 切换走片划痕线工具 |
| `Shift + B` | 切换加深与减淡蒙版绘制 |
| `Shift + R` | 切换分析区域绘制 |
| `Shift + T` | 打印密度 × 反差等级试条 |
| `Shift + F` | 打印彩色环围试条（品红/黄滤色） |
| `\|` | 预览平扫（数字中间预览） |
| `Esc` | 第一次按下清除正在放置的点。第二次放下工具 |

## 几何与方向
| 按键 | 操作 |
|-----|--------|
| `[` | 逆时针旋转 90° |
| `]` | 顺时针旋转 90° |
| `H` | 水平翻转 |
| `V` | 垂直翻转 |

试条或环围试条显示期间，`[` 和 `]` 转动的是该样张的阶梯，而不是图像。

## 系统操作
| 按键 | 操作 |
|-----|--------|
| `Ctrl + E` | 导出当前图像 |
| `Ctrl + Z` | 撤销上一次更改 |
| `Ctrl + Y` | 重做更改 |
| `Ctrl + C` | 从当前图像复制设置 |
| `Ctrl + Shift + C` | 连同该帧的归一化边界复制设置 |
| `Ctrl + V` | 将设置粘贴到当前图像 |
| `Ctrl + ,` | 打开偏好设置 |

## 视口
| 按键 | 操作 |
|-----|--------|
| `Ctrl + [` | 显示/隐藏会话面板（浮动时重新停靠） |
| `Ctrl + ]` | 显示/隐藏控制面板（浮动时重新停靠） |
| `Ctrl + Shift + L` | 停靠会话面板与控制面板 |
| `鼠标滚轮` | 放大 / 缩小（最高 400%）；偏好设置中的**反转滚轮缩放**可翻转方向 |
| `中键单击` + `拖动` | 平移已放大的图像 |
| `左键单击` + `拖动` | 平移已放大的图像（没有工具处于激活状态时） |

## 菜单栏（仅 macOS）

NegPy 在 macOS 上有菜单栏：**偏好设置…**位于应用程序菜单中，还有**窗口**和**帮助**菜单。这些按键来自菜单栏。它们是平台窗口命令，不是 NegPy 操作，因此是固定的，不会出现在快捷键编辑器中。

| 按键 | 操作 |
|-----|--------|
| `⌘ + M` | 最小化前置窗口 |
| `⌘ + W` | 关闭前置窗口（关闭主窗口即退出 NegPy） |

其他每个菜单项都使用上文列出的、其操作对应的绑定，并且只在该绑定使用 `⌘` 时才显示它。绑定到普通按键的快捷键仍可从键盘触发；菜单只是不把它印出来，因为 macOS 让菜单按键优先于一切，一个普通的 `?` 会在你往文本框里打字时触发。
