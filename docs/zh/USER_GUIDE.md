# NegPy 用户指南

> **简体中文翻译** · 译自 [`docs/USER_GUIDE.md`](../USER_GUIDE.md) · 对应 NegPy v0.58.0 · 若有出入,以英文原文为准

NegPy 用一条非破坏性、暗房风格的流水线，把胶片扫描变成完成的正像。它绝不会回写你的源文件。每处编辑都存放在本地数据库中，因此你可以放手尝试。

本指南面向新用户，解释每个控件的作用以及何时该用它。想了解流水线*为何*按此顺序排列，请阅读 [PIPELINE.md](PIPELINE.md)。

---

## 1. 总览

### Windows 上受保护的数据文件夹

如果 Windows 阻止写入 NegPy 的默认数据文件夹，NegPy 会建议使用 `%LOCALAPPDATA%\NegPy\data`。点击该路径可另选文件夹，然后选择 **Use This Folder**。不会复制或移动任何数据：新文件夹以全新设置开始、没有已保存的编辑；已有的 NegPy 数据文件夹则使用其自身的数据。你的原始数据留在原处。对话框还会说明如何让 NegPy 通过 Windows 的文件夹保护、继续使用原文件夹。NegPy 会把你的选择记在 `data-location.json` 中，即使 Documents 之后变为可写也是如此。显式设置的 `NEGPY_USER_DIR` 优先级更高。已保存的文件夹若无法访问，NegPy 会报错，而不会切换到其他数据。

### 屏幕布局

*   **左侧，胶片条**：以接触印相形式显示你载入的帧，外加导入、排序与初筛工具。
*   **中间，画布**：实时预览。大多数工具（裁剪、白平衡吸管、修复画笔、加深/减淡蒙版）都直接在它上面点击使用。滚动或捏合可缩放，拖动可平移。底部有一条浮动工具栏，放着适应窗口/1:1 缩放（**1:1** 指一个扫描像素对应一个屏幕像素，处于该比例时会亮起；低于 **HQ** 时预览会被放大到该尺寸，画布上的 **preview res · HQ off** 胶囊会提示这一点）、撤销/重做、旋转/翻转等，窗口变窄时溢出的项目会移入 **⋯** 菜单。放不下的内容从右侧收起，而无论工具栏显示什么，**⋯** 菜单都保留每一个操作。该菜单中的 **偏好设置…** 收纳了所有应用全局设置（§14）：界面选项、性能预算、决定哪些控件排在工具栏上及其顺序的 **编辑工具栏…**，以及决定哪些设置沿用到你打开的下一个文件的 **持久化设置…**。右键点击图像可得到 **重置视图** 和 **固定缩放**（切换帧时保持当前缩放），外加吸管工具和复制/粘贴设置。未载入任何内容时，画布显示 **载入一些扫描件以开始**；点击它即可 **添加文件** 或 **添加文件夹**。
*   **左侧，胶片条**：以接触印相形式显示你载入的帧，外加导入、排序与初筛工具。
*   **中间，画布**：当前帧的实时预览。大多数工具（裁剪、白平衡吸管、修复画笔、加深/减淡蒙版）都直接在它上面点击使用。滚动/捏合缩放、拖动平移；底部有一条浮动工具栏，放着适应窗口/1:1 缩放（**1:1** 指一个扫描像素对应一个屏幕像素，处于该比例时会亮起；低于 **HQ** 时预览会被放大到该尺寸，画布上的 **preview res · HQ off** 胶囊会提示这一点），以及撤销/重做、旋转/翻转等，窗口变窄时溢出的项目会移入 **⋯** 菜单。放不下的内容从右侧收起，而无论工具栏显示什么，**⋯** 菜单都保留每一个操作。该菜单中的 **偏好设置…** 收纳了所有应用全局设置（§14）：界面选项、性能预算、决定哪些控件排在工具栏上及其顺序的 **编辑工具栏…**，以及决定哪些设置沿用到你打开的下一个文件的 **持久化设置…**。右键点击图像可得到 **重置视图** 和 **固定缩放**（切换到另一帧时保持当前缩放级别，而不是重置为适应窗口），以及吸管工具、复制/粘贴设置和 **卸载**（从会话中移除该帧；其已保存的编辑会保留）。未载入任何内容时，它显示 **载入一些扫描件以开始**；点击它即可 **添加文件** / **添加文件夹**。
*   **右侧，控制面板**：顶部是固定的 **分析** 读数，下方是一条图标选项卡栏。每个图标打开一个*工作流页面*，其中含一个或多个可折叠面板。

### 前后对比

画布工具栏的 **◑** 按钮（或 `\`）把画布一分为二。分隔线左侧是自动基线：同一帧、相同的胶片工艺、裁剪和旋转，但每个创意控件（曝光、色调、Lab、加深/减淡、调色、修尘和成品输出）都回到默认值。右侧是你的编辑。拖动分隔线可移动分界，或抓住中间的圆钮。

分屏在你工作期间保持显示，因此拖动滑块时，后侧会相对一个固定参照变化。再按一次 `\`，或切换到另一帧，即可关闭它。预览底片、预览平扫和试条会接管画布，因此它们也会关闭分屏。

### 预览底片

画布工具栏的胶片按钮（或 `N`）按载入时的样子显示扫描：底片，未反转，没有测光、没有片基归一化，也没有你的任何编辑。用它来评判扫描本身而非印相：这一帧是薄还是厚、色罩究竟是什么颜色、扫描仪是否溢出了。它不改变任何东西，一碰控件就关闭。你的裁剪、旋转和翻转仍然生效，因此画面停留在你摆放的位置。该帧经过色彩管理，所以 C-41 色罩在这里和在文件里一样橙；Linear RAW 不改变它的观感——窄带采集除外，那里白平衡完全不起作用（没有全光谱场景可供它描述），因此 Linear RAW 开启时显示真正中性的扫描，关闭时显示相机自身（无意义的）拍摄时偏色。软打样保持关闭：这是扫描，不是印相。

### 工作流程（以及各步骤的先后顺序）

右侧的选项卡按你工作的顺序排列，与处理流水线的顺序一致：

| 选项卡 | 图标 | 面板 | 用途 |
|-----|------|--------|---------------|
| **设置** | 齿轮 | 预设 · 校准 · 工艺 · 整卷分析 | 胶片类型、采集端的颜色校正、底片→正像归一化、整卷基线 |
| **几何** | 裁剪 | 几何 · 平场校正 | 裁剪、拉直、镜头与衰减校正 |
| **曝光** | 太阳 | 滤色 · 色调 · 加深与减淡 | 白平衡、印相密度/对比度/曲线/饱和度、局部加深 |
| **颜色** | 调色板 | Lab · 替代工艺 · 调色 | 彩度、锐化、效果、Lith 与蓝晒印相、分离与化学调色 |
| **成品** | 画笔 | 修尘 · 成品输出 | 除尘、暗角、边框、片夹 |
| **收藏** | 星形 | 你挑选的滑块 | 快速访问你最常用的控件 |
| **历史** | 时钟 | 工作样张 · 编辑历史 | 保留命名版本，逐步回退每一处更改 |
| **导出** | 文件 | 导出设置 | 格式、大小、颜色、批量输出 |
| **元数据** | 标签 | 归档元数据 | 原始相机、镜头和胶片信息 |
| **扫描** | 相机 | 扫描仪 · 相机翻拍 | 直接采集胶片（Linux/macOS） |

你不必动每个面板。默认值经过调校，能直接产出不错的印相，多数帧只需要裁剪、也许微调一下白平衡，然后导出即可。

面板标题上、以及选项卡图标上的一个小**圆点**，表示你把某项设置改离了默认值。每个面板标题都有一个**重置**操作和一个 **ⓘ**，后者会打开本指南并定位到该面板对应的章节。

两侧面板都可以收窄，给画布腾出更多空间。控制面板变窄时，放不下的选项卡图标会移入选项卡栏右侧的 **»** 菜单。你当前所在的选项卡始终可见。

### 哪些设置会沿用到下一帧

打开一个你没编辑过的帧，它并非从完全的默认值开始：那些属于*设备和整卷*、而非属于这张画面的设置会随之带入：胶片工艺、裁剪比例、翻转、校准、相纸、Lab 润饰以及你的导出偏好。而观感本身（密度、滤色、色调曲线、调色、加深与减淡）在每一帧上都从干净状态开始。

**偏好设置 → 会话与存储 → 持久化设置…** 可更改这份列表。复制/粘贴选择器知道的每一项设置都在这里，按面板分组；勾选一项即让它沿用，取消勾选即阻止它沿用。通过组标题的复选框可勾选整组。显示的值取自你上次保存的编辑，因此这份列表呈现的正是实际会沿用的内容。

已经编辑过的帧会保留自身观感，无论你勾选了什么，因为只有导出和元数据设置能作用到它。对一帧执行 **重置设置** 会忽略这份列表，把它恢复到完全的默认值。

### 菜单栏（macOS）

本指南中的 `Ctrl` 在 macOS 上为 `⌘`，应用里的每个菜单、工具提示和快捷键列表都按此显示。

在 macOS 上，NegPy 有一条菜单栏。其中几乎没有新东西：除了报告问题，每一项执行的都是某个按钮、窗口控件或键盘快捷键已经能执行的操作。

*   **NegPy**：偏好设置…（`⌘,`），macOS 把它显示在应用菜单中，紧邻 About 和 Quit。
*   **窗口**：最小化（`⌘M`）、缩放、关闭（`⌘W`）和全部前置，随后列出每个打开的 NegPy 窗口（主窗口外加任何实时取景或校准窗口），并对最前面的窗口打勾。选择某个名称即可把该窗口调到前面。窗口处于全屏时，最小化和缩放不可用，这与 macOS 其他地方的行为一致。
*   **帮助**：查看功能导览、键盘快捷键、自定义快捷键、分析面板指南、报告问题（在浏览器中打开 NegPy 的问题跟踪页），以及检查更新。

全屏由 macOS 自身管理，因此 NegPy 不为它添加菜单项：使用绿色的窗口按钮即可。对于拥有 View 菜单的应用，macOS 会把 Enter Full Screen 项放进去，而 NegPy 的 View 菜单是之后才有的。

只有当某个按键使用 `⌘` 时，菜单才会显示它。绑定到普通按键的快捷键（例如键盘快捷键的 `?`）仍然有效，但菜单无法占用它：macOS 让菜单按键优先于一切，因此菜单里的普通 `?` 会在你往胶片条搜索框输入 `?` 时被触发。重新绑定某个快捷键后，其菜单项会随之更新。

在主窗口上按 `⌘W` 会关闭 NegPy。Windows 和 Linux 没有菜单栏；那两个平台没有任何变化。

## 2. 胶片条（左侧面板）

标题区显示 NegPy 标志和版本号。版本号旁边的 **↻** 按钮可按需向 GitHub 查询是否有更新版本；有新版本时它会变成绿色的 **⬇**。有新版本时，版本号下方还会出现一行绿色的 **⬇ 有可用更新**；点击其中任意一个即可查看更新内容并让 NegPy 安装它（[§15](#15-更新-negpy)）。标题区右上角的折叠箭头可把标志收起来，给帧腾出更多空间。

标题区下方是：工具栏、搜索框，以及两个可折叠分区。**图库** 收纳你的扫描件所在的文件夹；**胶片条** 收纳你打开的帧。点击任一标题即可把它收起；仍然展开的那个会占据整个面板。NegPy 会记住哪些是展开的。

### 你的图库

**图库** 分区是一棵文件夹树，列出你的扫描件所在的位置。按 **+** 添加一个文件夹，把它指向你存放所有内容（连同子文件夹）的那个总 `Scans` 目录。**↻** 会从磁盘重新读取。每一行显示其中的内容（“36 张照片”、“2 个文件夹”），子文件夹在你展开时才会读取。

**浏览不产生任何开销。** 当你添加文件夹或在树中点击浏览时，NegPy 不会打开、解码或哈希任何文件。它只列出里面有什么。

#### 图库按钮

**图库** 按钮（书本图标，工具栏第一个，或 **Ctrl+L**）打开你的扫描件所在的文件夹。第一次按它时，NegPy 会让你挑选那个文件夹并记住它。面板还会自行回到那里：启动时若你没有恢复会话，以及每当你卸载最后一帧时。比起一张空白的接触印相，你的整卷胶片是更有用的停留状态。

要让它指向别处，用 **+** 添加另一个文件夹。要全部忘记，使用*管理数据库*中的 **清除图库**。这只清除文件夹列表，你的图像、文件夹和编辑都不受影响。

#### 四处浏览

*   **单击**文件夹可选中它，**双击**（或 **Enter**）可打开它。
*   **Ctrl+单击**多个文件夹并一起打开，可一次载入多卷胶片。NegPy 只询问一次，针对总数。
*   **Alt+Up** 把选择移到上面的文件夹。
*   文件夹树的排序方式与接触印相一致。把 **排序** 改为日期或降序，文件夹会随之调整。

当你打开一个含有图像的文件夹时，NegPy 会询问是否 **加载胶卷**。只有这时它才会对它们做哈希并生成缩略图，这正是大卷胶片上会花一点时间的部分。选择否，你已打开的帧保持原样。如果你更希望它直接开始，在提示中勾选 **始终直接加载，不再询问**。

加载一卷会替换胶片条中的内容；右键 → **添加到会话** 则改为追加。无论哪种方式都不会丢失任何东西，因为你的编辑存放在 NegPy 的数据库里，而不在打开文件的列表中。

#### 文件夹始终是你的文件夹

NegPy 直接从磁盘读取这棵树，绝不在其中创建、重命名、移动或删除任何东西。在 Finder 或资源管理器中重新整理后，下次刷新时树会显示新的排列。每处编辑都按图像内容存储，因此在文件夹之间移动文件会保留它的编辑、历史和保留/排除标记。

### 导入与管理文件

**关于尼康 High Efficiency raw 的说明。** Z 8 和 Z 9 可以用 **High Efficiency (HE)** 或 **HE\*** 记录 NEF，它们使用一种 NegPy 无法解码的受许可编解码器。这样的文件仍叫 `.NEF`，仍带有与普通无损 NEF 相同的 TIFF 压缩标签，因此在打不开之前看起来毫无异常。NegPy 会指明具体原因，而不是报告一个笼统的“文件不受支持”错误。请改用 **Lossless Compressed** NEF 重新拍摄，或用 Adobe DNG Converter 转换。来自相同相机的无损 NEF 可正常打开。

工具栏按钮，从左到右：

*   **添加文件** / **添加文件夹**：载入单张图像或一个文件夹中的所有图像。如果选中的文件夹只装着*其他*文件夹，NegPy 会在图库分区中展开它，而不是报告什么都没找到。把文件夹拖到窗口上效果相同。
*   **全部清除**：卸载所有内容，或仅卸载所选帧。
*   **热文件夹**：监视当前文件夹，并在新文件出现时自动载入，当扫描仪或联机应用把文件放入某个目录时很方便。开启期间，“工作中…”导入弹窗保持隐藏，因此每个新帧不会弹出窗口；画布上方的状态行仍会报告导入情况。
*   **三色扫描**（三次曝光的窄带采集，也称三色采集）：把文件夹当作红/绿/蓝曝光三联组，并从三张拍摄合成每一帧。拍摄按它们被摄取的顺序分组，顺序读自文件本身，因此文件名无需遵循任何约定。在转向下一帧之前，连续摄取每一帧的三次曝光。当某个文件未记录拍摄时间时，文件夹退回按文件名排序，此时文件名必须能排出拍摄顺序。右键点击某帧 → **编辑 RGB 三色曝光组…** 可手动指定这三个文件。只有当三张拍摄每种颜色各有一张*且*显示同一帧时才会被合成；不满足时，它们会作为独立的帧留下、供手动配对，而不会被错误地合成。合成后的帧带有[初筛](#初筛剔除整卷废片)下所述的三点徽标。
*   **半格**：把每个扫描件分成两帧，用于半格相机。每一半分别编辑和测光，并标注它是哪一半。启用它会在当前扫描件上打开一个矩形编辑器：拖动绿框进行裁剪（框外的一切都被丢弃），拖动橙线设置分割位置，用 **切割宽度** 丢弃以分割线为中心的一条带——也就是两次曝光之间物理上的黑色分隔条。该设置会被保存，并从此应用于每一次半格分割，无论扫描件是用什么方式获取的（SANE 扫描仪、相机翻拍架，或文件夹导入）。**调整半格** 位于半格旁边，可重新打开编辑器。对间隔的自动检测仍会为初始分割位置提供起点。

    关闭半格不会丢失工作成果：你编辑过的每一半都保留各自的编辑。只是看过、没编辑的一半不算工作成果，因此把半格开了又关，扫描件会保持原样。你确实分割过的扫描件会作为一帧返回，承载两半，即一张**二联片**：第 1 半用自身的编辑渲染，第 2 半用自身的编辑渲染，按原始间距并排拼接，切割带作为黑色间隙。若某扫描件的两半携带的是来自另一个文件夹或更早会话的编辑，它就不是二联片；它保持为一个普通帧，直到你再次分割。二联片带有两侧都填充的分割徽标，并导出为一个名为 `<name>-DIPTYCH` 的文件。它的控制面板被禁用，因为编辑属于那两半：重新打开半格才能更改其中任何一半。只处理过一半的扫描件，两侧都使用那一半的编辑。胶片条缩略图和接触印相格仍显示普通的完整扫描件，因此二联片的缩略图与它导出的内容不一致。设为长边的导出尺寸会应用于每一半，因此二联片导出后的宽度约为该值的两倍。要取回普通帧，右键点击二联片并选择 **取消二联片分割**：它会重新整体渲染和导出，两半的编辑都会被删除，因此之后的分割会从默认值开始。

    半格不适用于由多个文件合成的帧：三色三联组、拼接或 HDR 合并。它们永远不会被分割，也永远不会作为二联片返回，即使它们所围绕的那个文件之前曾被当作两半处理过。
*   **应用（克隆）**：把当前帧的设置复制到所选帧或整卷。你在对话框中选择哪些方面；裁剪和旋转始终按图像单独处理。
*   **接触印相筛选**（漏斗图标）：显示*全部帧*、*仅保留帧*，或*隐藏已排除帧*。该选择会在会话之间记住，并应用于你打开的每一卷。
*   **排序**：按名称或日期，升序或降序。

两个分区上方有一个**筛选框**、一个 **`.*`** 正则切换和一个**搜索图库**按钮。胶片条分区内有一个**计数**，例如“36 帧 · 12 个保留帧 · 3 个已排除帧”。当筛选隐藏了部分帧时，计数会同时统计两组并标明筛选条件，例如“3 / 36 帧 · 保留帧筛选”。当筛选隐藏了所有帧时，胶片条会显示一条消息，带一个 **显示全部帧** 链接，点击它会同时清除筛选框和漏斗筛选。

#### 筛选接触印相

输入一个普通词语，它会匹配文件名。除此之外，筛选框还接受 `field:value` 形式的条件，用它可以按一帧*是什么*、而非它叫什么来查找：

| 条件 | 查找 |
|---|---|
| `film:portra` | 胶片名包含“portra”的帧 |
| `camera:"Nikon F3"` | 含空格的内容要加引号 |
| `iso:>=400` | 数值字段还接受 `>`、`>=`、`<`、`<=`（`iso`、`frame`、`push`、`devtime`、`temp`） |
| `date:2024-03` · `date:>=2024` | 按文件日期；不完整的日期作为前缀匹配 |
| `shot:1998` · `shot:>=1998-07` | 按元数据面板中的拍摄日期，而非文件日期 |
| `place:tokyo` | 按拍摄城市、省/州或国家 |
| `devtime:>=9` · `temp:20` | 显影时间（分钟）和温度（°C） |
| `roll:` `developer:` `dilution:` `lens:` `format:` `scanning:` | 元数据面板的其余字段 |
| `name:` `path:` `ext:tif` | 文件标识 |
| `keeper:` `rejected:` `edited:` | 带有该标记的帧，或有已保存编辑的帧 |
| `-rejected:` `-film:velvia` | 前导 `-` 对任何条件取反 |

各条件以 AND 组合，因此 `film:portra iso:>=400 -rejected:` 会同时应用全部三条。元数据来自每一帧自己的 **元数据** 面板，所以填好之后即可搜索；从未编辑过的帧仍可按名称、扩展名、日期和标记找到。**`.*`** 切换把筛选框切回对文件名的普通正则匹配，忽略字段语法。

#### 搜索整个图库

筛选框缩小的是已经打开的内容。它旁边的**文件夹放大镜**按钮（或在框中按 **Enter**）会在每个图库文件夹中运行同样的搜索并载入找到的内容，因此 `film:portra` 能在你这个月没打开过的文件夹里找到你的 Portra 帧。状态栏会边搜索边统计文件数。

这无需打开任何东西即可工作，因为 NegPy 已经知道哪处编辑属于哪个文件。胶片、相机等信息来自你填写过的帧。这些文件夹只被读取，绝不在后台建立索引，也绝不被修改。

在胶片条的**空白处**右键点击，可得到 **添加文件**、**添加文件夹** 和 **全部清除**，这样在长卷胶片中途也能顺手用到这些工具。这里的 **全部清除** 始终指整个会话，绝不只针对所选内容。

#### 用多张拍摄拼接一帧

如果一张底片是用翻拍架以高于单帧的放大倍率、分成相互重叠的若干部分摄取的，选中这些部分并右键 → **拼接所选帧**。NegPy 会找到重叠区、匹配接缝两侧的亮度，并把这些部分替换为一个名为 *a+b (Stitch)* 的宽幅合成图，在接触印相上带有徽标。各部分在文件中保留自己的编辑，因此右键 → **取消拼接** 能把它们原样放回。配准信息会被保存并重放，因此合成图在跨其他文件夹、其他启动时都保持完整，直到你取消拼接，而重新打开它不产生任何开销。

这对三色帧也适用。先打开 **三色扫描**，让每个部分都已从其自身的 R/G/B 三联组合成，然后拼接这些合成好的帧。每个部分保留自己的三次曝光，各部分之间不共享任何内容。

#### 合并包围曝光（HDR）

正片的密度范围比单次相机曝光能记录的更深。按高光曝光，最暗的部分就落在传感器噪点里；按暗部曝光，明亮的部分就溢出。改用包围曝光：对同一张正片间隔一挡拍几张，然后选中它们并右键 → **合并曝光（HDR）**。它们会合并成一帧，名为 *a +4 (HDR)*，承载整个范围，在接触印相上带有徽标，因此合并图绝不会与单次拍摄混淆。右键 → **取消合并曝光** 能把原始帧放回，它们各自的编辑不受影响。

无需事先做任何设置。NegPy 从图像本身测量曝光，而不信任快门标签——因为若干受支持的扫描仪格式根本没有快门标签——算出它们之间相差几挡，并把它们相互配准，以防相机发生过移动。结果会被保存并重放，因此合并图在跨其他文件夹、其他启动时都保持完整，直到你取消合并，而重新打开它不产生任何开销。

**它如何落位。** 这是两个应当分开的不同选择。合并以*不溢出的最长曝光*为单位*计算*：从辐射度量看这是最佳参照，因为其他每一帧都转换到它，且没有任何内容能超过白色。而画面随后*以哪一挡曝光呈现*是另一个问题，且不是软件能回答的。正片最亮的点比透明片基更厚，因此不溢出的最长拍摄比你测光的那张更亮，在那里渲染会把高光推到传输曲线顶端、曲线剩余斜率最小的地方。那看起来像是丢失了高光细节，而事实正是如此。

**所以自己指定那一帧。** 右键点击合并后的帧 → **渲染曝光**，挑选那张看起来符合你意图的拍摄。合并图就恰好以它呈现，其他帧只贡献范围和干净程度。列表以相对参照的挡数显示每一帧，参照本身标为*（按拍摄原样）*。

列表中只有参照以及任何**更短**的曝光。合并图呈现的亮度绝不会超过参照（即定义白色的那一帧），因此更长的帧渲染结果完全相同，不会被列出。如果某组包围曝光在参照之下没有任何帧，菜单就不会出现。

**或把它设为一个数值。** 选中合并后的帧时，工艺面板会多出一个 **渲染曝光** 滑块：0 EV 是参照，即合并图能呈现的最亮处，向下一直到 −4 EV。下方的菜单吸附到你实际拍摄过的曝光；滑块可在它们之间任意取值，而你想要的那一档通常就在两者之间。设定数值会清除你之前指定的帧，挑选某一帧会清除该数值，因此任何时候只有一者生效。

保持在 **包围曝光中间帧（自动）** 时，它会退回包围组的中间曝光。只有当你在测光那张的两侧均匀包围时，这才是合理的猜测。若向*上*包围，每一帧都位于参照处或其之上，因此中间值落在参照上，该设置不起任何作用。

**把那张看起来已经正确的拍摄包含进来**，并至少再加一张比它更暗的。只向上包围很有诱惑力，因为比参照*更长*的帧才是买来暗部的那些。别这么做：菜单只能提供你实际拍过的帧，所以你能要求的最暗渲染就是包围组中最暗的曝光。参照通常落在**测光帧之上一到三挡**，且绝不是测光帧本身，因此*（按拍摄原样）*并不是你拍的那一挡，你想要的那一挡通常在它下方一到两挡。

合并买来的是最深暗部里的信噪比，约值两挡，而中间调保持不变。这份收益完全落在正片（反转片）最难扫描之处。

**合并打开时，其暗部已被提亮**，提亮量由包围组恢复出的范围导出，因此**阴影密度**不在零位。这是刻意为之。如果你测光的那张没有溢出，合并添加的就不是*范围*，而是*精度*：那些色调全都被记录了，只是在噪点之上只有极少的级数。精度在同一色调处是不可见的，因此一个保持中性的合并，其渲染结果与它据以测光的那一帧无从分辨，而那不是你合并的目的。这种提亮是被测量出来的，而不是一种观感：它只走到恢复出的精度所能负担的程度，因此打开后的暗部仍比单帧的暗部更干净。把**阴影密度**拖到零，可得到忠于测光那一帧的渲染，而该选择会像任何其他编辑一样被保存。**重置设置**会把预置的起始点连同合并本身及其继承的胶片工艺一起恢复回来。

向**两个方向**包围，出于两个不同的原因。

**向上，为了范围。** 更长的曝光能触达深暗部，并由它们设定参照。测光那张、+1、+2，暗部很深时再加 +3。

**向下，为了选择。** 更短的曝光对*像素*几乎没有增加，因为参照在构造上已经保住了高光。它们的作用是出现在 **渲染曝光** 菜单里，而一个合并图的可调程度取决于你给它的帧。停在测光那张，菜单只提供两个条目，没有再变暗的余地；向下到它下方两挡，就有四到五个条目，可达 −3 和 −4 EV。

从测光那张的 −2 到 +3 需要六帧，并把决定权留到最后给你自己。如果必须节省，就向上节省：多一张长曝光买来的是你未必会留意的暗部噪点，多一张短曝光买来的是你日后无法再做的选择。

更短的帧确实直接带来一样东西：**溢出的镜面高光**，也就是超出参照白色之上的那一线水面高光或太阳圆盘。

合并后的帧继承其来源曝光的**胶片工艺**，因此一组正片包围会以正片（反转片）模式打开，而不会退回你上次手动设置的任何模式。拼接合成图也是如此。

它**以文件名顺序中的第一帧命名**，并带 `-HDR` 后缀，因此一组 `_DSC1715`…`_DSC1719` 的包围会导出为 `_DSC1715-HDR.jpg`。不用参照帧命名，因为参照帧的身份取决于画面内容；而这个后缀意味着合并图绝不会覆盖它所依据命名的那个单帧的导出文件。

**合并是为透明正片设计的**，因此该操作只出现在正片（反转片）帧上。彩色负片从其片基到最厚的高光之间约有 5-6 挡，普通黑白负片接近 4 挡，两者都轻松落在单次拍摄之内。透明正片可达 10-12 挡，这正是合并存在的理由。在黑白上该条目显示但禁用，因为反转冲洗的单色胶片（Scala、dr5、Fomapan R）确实是透明正片、也确有那样的范围。只是它尚未接通。

对已经合并、拼接或属于三色三联组的帧，也会拒绝合并。每一种都是用多个文件构建一帧的独立方式，不支持把它们组合起来。

收窄面板时，放不下的工具栏按钮会移入其右边缘的 **»** 菜单，因此你可以把面板压窄而不丢失任何工具。

### 初筛（剔除整卷废片）

缩略图从一开始就是正像。你尚未打开的帧会直接从其预览反转，这是逐通道的快速处理而非完整流水线，因此你在筛选时看到的接触印相就是一张张照片。打开一帧后，它的缩略图会被真实渲染替换，与画布完全一致。透明正片则原样保留，因为它们已经是正像：凡是你已设定胶片工艺、或已打开过一次的帧，都以你的设定为准，只有尚未被任何设置确定过的帧才会从其预览去猜测。

在审阅接触印相时，右键点击缩略图或使用键盘快捷键来标记帧：

*   **保留**：一个小的对勾徽标标记保留帧。
*   **排除**：一个叉号徽标使该帧变暗。被排除的帧仍留在接触印相上，但会被批量导出和附属文件写入跳过。**磁盘上的文件绝不会被动。**

标记可应用于多选，并在会话之间持久保存。右上角的徽标则用于标示解码失败的帧。

#### 读懂徽标

缩略图的每个角各表示一件事，因此这些标记绝不相互冲突：

| 角 | 徽标 | 含义 |
|---|---|---|
| 右下角 | 对勾 | 保留帧 |
| 右下角 | 叉号，帧大幅变暗 | 已排除 |
| 右上角 | 感叹号 | 文件解码失败；点击重试 |
| 左下角 | *见下文* | 该帧由多个文件构建 |

左下角的徽标是灰色而非红色，因为它报告的是这一帧*是什么*，而不是你标记的东西。它的图形说明是哪一种：

| 图形 | 帧 |
|---|---|
| 两块重叠的窗格 | 拼接合成图（[§拼接](#用多张拍摄拼接一帧)） |
| 三条堆叠的横条 | 合并的包围组（[§合并](#合并包围曝光hdr)） |
| 红/绿/蓝三个圆点 | 三色三联组 |
| 一个分割的矩形，一侧填充 | 半格扫描的一半；填充的一侧表示是哪一半 |
| 一个分割的矩形，两侧都填充 | 二联片：整个扫描件，每半各有自己的编辑 |

悬停在任意缩略图上，工具提示会用文字说明同一件事，并带上帧数：*5 次曝光的 HDR 合并*、*3 帧的拼接合成图*。

右键菜单还提供 **复制/粘贴设置**（带或不带归一化边界）、**重置设置**、**应用设置…**，以及逐帧导出。带边界复制的设置会在粘贴选择器中把它们列为 **归一化边界**，处于勾选状态；取消勾选即可只粘贴观感、保留该帧自己的边界。

## 3. 分析读数（始终可见）

固定在选项卡上方，这是你印相时的反馈来源。拖动分隔线可调整它的大小，或把它整个收起。其中的一切都在描述你当前所在的帧，并随你的编辑而更新。分区条是其中唯一还能让你通过它进行操作的部分。自上而下：

#### 光度曲线

这张图是 NegPy 此刻正透过其进行印相的相纸特性（H&D）曲线。它模拟一张相纸如何响应，而不是一个曲线编辑器。从左到右是**底片密度**，即相纸接收到的曝光，因此底片上厚的部分（场景的高光）位于右侧。从下到上是最终得到的**印相色调**。曲线越陡意味着对比度越高，这正是反差等级所移动的。两端的变平处是趾部（暗部）和肩部（高光），在那里相纸耗尽了它的范围。

调入**对比度蒙版**后，曲线与一条虚线边缘之间会展开一条紫罗兰色带。蒙版按每个像素自身值与其模糊后周边值的偏离程度来移动它，因此它没有单一的曲线：大块平坦区域印在虚线边缘上，精细细节印在实线曲线上，其余一切都落在两者之间。这条带就是蒙版的作用范围。加深/减淡、局部反差等级和 CLAHE 在空间性上与此相同，并且有意不出现在这张图上——图画的是全局曲线。

十字线标出**支点**，即你改变对比度时曲线围绕其旋转的那个密度，因此中间调保持不动。当你拖动滑块时，上一条曲线的一道淡淡**残影**会留在后面供比较。如果去偏色把各通道拉开，你会得到三条分开的 R/G/B 轨迹，而不是一条灰色曲线，而那份张开*就是*颜色校正本身。

#### 两个直方图

两个不同的直方图共用这张图。曲线后面、从底部升起的是**输出直方图**：你正在看的这张印相的色调，以 R、G、B 和明度表示。沿底部横轴的是**底片密度直方图**，即扫描在曲线之前所包含的内容。

把它们对照着读。密度直方图告诉你底片占据横轴的哪一段，曲线则告诉你那一段会发生什么。如果底片的数据完全落在平坦的趾部上，再多的对比度也无法把那些暗部分拉开。应改为移动曝光，让数据落到陡峭的中段。

预览底片显示的是任何曲线运行之前的扫描，因此图中会去掉曲线、输出直方图和分区条，而密度直方图自身会拆分成 R、G、B 和明度，因为已经没有印相直方图来承载颜色信息了。每个通道按各自的峰值缩放，因此钉在左边缘或右边缘的尖峰就是该通道在溢出，而与其他通道明显分离的轨迹则是强烈的偏色。

#### 线性 / 对数切换

图的右下角。它切换的是直方图的*高度*轴（有多少像素），而不是色调轴。**线性**是如实的，因此一大片平坦的天空会让其他一切都相形见绌。**对数**压缩高耸的峰值，让细薄的尾部变得可见，而深暗部或镜面高光那几百个像素就住在那里。用对数来找溢出，用线性来判断画面的主体落在哪里。NegPy 会在会话之间记住这个选择。

#### 溢出三角标

图顶角上的小 R、G、B 三角形。**左上角**是被压到纯黑的暗部，**右上角**是冲爆到纯白的高光。只有当某个通道超过画面的 0.5% 时它们才会出现。有一点是正常的，因为真实的印相是有黑位的。要留意单个通道独自溢出，那是偏色把某种染料推出了末端，而不是曝光问题。

#### 分区着色与分区刻度

左侧的琥珀色晕染和右侧的蓝色晕染标出曲线的趾部和肩部，也就是正在丢失色调分离的两个被压缩的末端。沿底部的刻度是亚当斯分区 I 到 IX，因此你可以直接从轴上读出某个底片密度会印成哪个分区。

#### 阶梯楔

一个 21 级、Stouffer 风格的灰楔，透过你当前的曲线印出，以均匀的密度增量排列，并用扫描自身的密度单位标注。它是曲线的一把标尺。相邻色块明显不同之处，说明你有色调分离；它们合并成一整块平坦的黑或白之处，说明那些色调已经没了。括弧标出可用的跨度。预览平扫时它会隐藏，因为那时没有可供楔入的印相曲线。

#### 分区条

亚当斯刻度上的十个格子，其中 **0 是相纸黑，V 是 18% 中灰**。最后一格（IX）还吸收相纸白。每个格子的亮度是该分区的色调，而它看起来有多实，则代表画面有多少落在那里。这是判断一帧是低调、高调还是稳妥地落在中间的最快读法。当暗部堵死或高光冲爆时，两端的格子会染成**红色**。悬停某个格子可查看它的确切百分比。

它也是你放置色调的地方。**点击一个格子，再点击照片上的那个点**，印相就会被解算，使该点落在那个分区上。见下文分区放置。已选定的格子会被描边，直到你使用它。再次点击它，或按 Esc，即可取消。

#### 探针

一个点密度计。悬停在图像上读取像素：各通道相对片基的密度（ΔD，相对于本次扫描的归一化，而非绝对密度）、所显示色调的反射印相密度，以及它的印相分区（0 = 相纸黑，V = 18% 中灰，X = 相纸白）。在黑白负片模式下，ΔD 各通道读取的是转换前的颜色记录。

#### 分区放置

把探针变得可操作，也正是暗房放大分析仪所做的事。**点击上方分区条上的一个分区，再点击照片上的那个点。** 印相会被解算，使该点印在你所要求的分区上，而且你立刻就能看到。用同样的方法要求第二个、第三个分区。第四个点会替换掉较近的那个固定点。每个固定点在这里显示为一行：它现在读到的分区，以及赋予它的**目标**，− 和 + 按钮以三分之一分区为单位微调目标。

有一个固定点时，解算印相密度，使那个色调印在它的目标上。有两个时（通常是一个暗部和一个高光），解算印相密度*和* ISO-R 反差等级，使两者都落位。第三个固定点会为它们之间的色调再增加一个控件：**阴影反差等级**、**高光反差等级**或 **Snap**，取其中真正能移动那个色调的一个，而这取决于它印在哪里，而非你把它称作哪个分区。按钮下方有一行字说明是哪一个，因此没有任何东西会悄无声息地移动；如果第三个色调已经印在你要求的位置，就不会碰第三个控件。

在你接受之前看到的都是预览。**分区放置**，或在照片上按 **Enter**，会把它提交为一次可撤销的编辑，关闭自动密度（有两个及以上固定点时还关闭自动反差等级），因为留着的测光会重新移动已放置的色调，然后关闭工具。一个固定点就足以接受。**Esc** 则改为丢弃：先丢弃已选定的分区，再连同预览一起丢弃固定点。某一行上的 **✕** 只移除那个固定点；移除最后一个，你就回到了已提交的印相。

固定点是手柄：拖动一个即可移动它，它旁边的分区会随移动重新读数（光标悬停在可抓取的固定点上时会变成一只手）。固定点在移动期间保持它所被要求的分区，其标注读作 `1 · IV⅓ → VI`，即它现在在哪里、你要求它印在哪里，两者一致时箭头消失。不先选择分区就点击照片，只是钉下一个读数，不改动印相。

要求一个相纸达不到的分区时，会显示一条琥珀色的 `→ 落于 …`，给出印相所能做到的最接近的分区，解算像分析仪顶到 5 号反差等级那样顶到滑块的末端。有三个固定点时，当三个要求无法同时满足，琥珀色也会出现：放置中间色调会推动外侧两个，因此解算在它们之间交替，并报告它们最终落在哪里。

固定点是校样，不是编辑。它们会叠加在任何其他编辑之上，切换帧时也依然存在。测得的分区透过印相曲线读数，与图和阶梯楔使用的是同一个模型，因此放置之后，固定点在构造上就读到它的目标；后续阶段（Lab、调色）仍会给悬停探针读到的最终像素蒙上差别。

#### 底片统计

底部的数值行。每一行悬停时都有同样的说明，且每一行测量的都是扫描而非你的编辑。前三行始终存在。其余各行只在有内容可报告时才出现：

*   **底片**：底片本身，以相对密度范围（明度）表示，外加它相对标准帧的冲洗特性：偏软（≈N−1）、正常、偏硬（≈N+1）。这是一个相对刻度，可在整卷之间比较，且是基于本次扫描归一化边界的启发式估算，而非校准过的密度计读数。
*   **曝光**：该帧中间调相对中性的位置，以挡为单位；正值更亮（高调），负值更暗（低调）。近似值，取自测光中间调。
*   **溢出**：被压至纯黑（暗部）或冲至纯白（高光）的像素占比，取最严重的通道。超过 1% 时变红。
*   **扫描溢出**：原始扫描中达到或超过传感器白色的像素占比，按通道显示。在底片扫描中，片基与场景暗部位于传感器白色附近，因此该处溢出会破坏片基与暗部的分离，且没有任何编辑能挽回。需在采集时修正：降低扫描曝光。超过 1% 时变红。
*   **修复**：IR 修复、灰尘检测和绘制的修复重写的扫描画面占比，仅在它们之一生效时才显示。叠加层显示修复落在哪里；这一行说明有多少。数值很大意味着阈值低到在重绘画面本身，而不只是画面上的灰尘。以整幅扫描为测量范围，包含边框。超过 5% 时变红。
*   **色域**：打样配置文件无法打印的画面占比，仅在你正针对某个配置文件打样时显示。溢出意味着某个色调跑出了相纸的末端；这一行意味着某种颜色超出了配置文件所能呈现的范围，因此打印会把它拉到最接近的可用颜色。零是正常读数。超过 2% 时变红。

## 4. 设置选项卡

**胶片模式**位于面板上方，因为它是每次编辑的第一个选择：**彩色**（C-41 彩色负片）、**黑白**（全色负片）或**正片**（透明/反转片，E-6 之类）。每个都会更换核心转换算法并从头重新运行流水线。它们旁边的魔杖按钮会在文件载入时**自动检测**模式。

<!-- panel:sensor -->
### 4.1 校准：你的设备对颜色的影响

这里的一切校正的都是*采集*，而不是观感。场景与你的文件之间隔着三样不同的东西：相机的色彩滤镜、胶片的染料，以及光源。每一样都有自己的控件。它们互不通用，任何一项都不能替代另一项。

**采集**，即在任何这些之前文件如何解码：

*   **扫描设置**（灯泡按钮）：一个两问向导，先问*你如何扫描？*再问*什么光源？*，据此为你设置 Linear RAW 和窄带。它在首次启动导览后运行一次，之后每当你的设备变化，该按钮都会重新打开它。
*   **Linear RAW**（默认关闭）：用中性乘数解码，得到完全原始的数据。关闭时，它用相机的拍摄时白平衡解码 RAW。切换它会重新载入文件。让**扫描设置**向导来选，或两种都试、留下结果更好的那个。**对三色三联组锁定为开**：窄带曝光没有全光谱场景可供白平衡增益描述，因此无论此开关如何，每个三联曝光都以中性解码。它保持可见并被记住，一旦该帧不再是三联组就再次解锁。
*   **窄带**：用一个随附的输入配置文件校正窄带（RGB-LED）采集特有的过饱和。普通宽带扫描请保持关闭。导出中显式指定的 Input ICC 会覆盖它。它在**正片（反转片）上变灰**；见下文*窄带与正片*。

向导按设备所做的设置：

| 采集 | 光源 | Linear RAW | 窄带 |
| --- | --- | --- | --- |
| 数码相机 | 白光（灯箱、CRI LED 面板） | 关 | 关 |
| 数码相机 | 窄带 RGB（Scanlight、RGB LED） | 开 | 开 |
| 胶片扫描仪 | 白光（Plustek、Epson、多数平板扫描仪） | 开 | 关 |
| 窄带扫描仪 | Nikon Coolscan、Kodak Pakon | 开 | 开 |

应用它会为新载入的文件设置默认值，更新已打开的帧，并重写会话中每个已编辑过的帧，每帧都可用 Ctrl+Z 撤销。

**单次窄带校准**适用于窄带光下的单次相机翻拍。相机的色彩滤镜与光源波段相互重叠，因此纯红曝光会渗漏一点进绿色和蓝色。这种渗漏是你的传感器与光源共同的固定属性，与胶片无关，因此在反转之前于线性采集上校正。

*   **配置文件**：要应用的传感器矩阵。自定义 `.toml` 矩阵位于 `<Documents>/NegPy/sensor/`。
*   **校准**（试剂瓶图标）：从三次裸光 R/G/B 曝光建立一个配置文件。

除非 **Linear RAW** 开启，否则此区块会变灰，因为配置文件是针对中性白平衡校准的，而拍摄时增益会错误地应用矩阵。它也因此在**正片（反转片）**上变灰，理由见下。无论哪种情况，你的选择都会被记住。对 RGB 三联素材也会跳过，它们从来没有这种渗漏。它会改变分析的读数，因此更改后要**重新运行批量分析**。

#### 窄带与正片

**窄带与单次窄带校准都不适用于正片（反转片）**，无论是否开启归一化。两者都保持可见但变灰，让你能看到设备设成了什么，两者都保留各自的值，而且一旦该帧重新变为底片，两者都会回来。

窄带是扫描底片的一种方式。它的收益——击败橙色罩、并在高增益反转之前干净地分离染料——是正片不需要的东西，而随附的配置文件描述的是对*底片*染料的窄带采集，正片并没有这种染料。单次窄带校准与之相伴：该矩阵针对你传感器的滤镜分离窄带光，因此它只对窄带光下所做的采集有意义，而对宽带采集没有办法建立这样一个矩阵。

这很重要，因为两者都会保留，并随你的设备从一帧跟到下一帧，因此一个为底片设置的配置文件本会原样落到你从未动过的正片上。如果你确实在窄带设备上扫描正片，请改用**色相微调**：它校正异常光源强加的色相旋转，而那正是可以被校正的部分。

**串扰**（在黑白负片中隐藏）是在反转之前应用于原始密度的通道分离。下拉菜单只列出你所处理胶片的矩阵，因为彩色负片矩阵并不描述正片的染料组，而不匹配的已存配置文件会被解析为不做校正，而不是做错误的校正。

胶片的每种染料都会吸收自身波段之外的光，但它们不是唯一的成因：你光源的光谱和你传感器的色彩滤镜也会混合通道，而在密度域中，三者都表现为同一类误差。因此请把矩阵当作*你的整套扫描装置*，而不仅仅是胶片。一个在某台设备上表现极好的配置文件，在另一台设备上用同一种胶片时可能是错的。

*   **矩阵**：要应用的配置文件，在下拉菜单中按其数字的来源分组（实测、在某台设备上调校，或来自规格表）。*Generic C41* 是内置的；把自定义 `.toml` 矩阵放进 `<Documents>/NegPy/crosstalk/`（见 [CROSSTALK.md](CROSSTALK.md)）。滑块按钮打开一个矩阵编辑器，其中一个**类型**控件记录该来源，一个**工艺**控件说明这些数字描述的是哪种胶片。工艺决定配置文件出现在哪里以及是否适用，因此你为正片建立的矩阵需要把它设为 E-6。用 **+** 创建的任何矩阵都已设为你正在处理的工艺。
    当当前胶片工艺完全没有矩阵时，下拉菜单和**强度**会被禁用，并有一条提示说明这一点。编辑器按钮保持可用，因为它是建立第一个矩阵的途径。
*   **强度**（0.0 到 1.0）：应用多少分离量，以获得更丰富、更干净的颜色分离。它会改变分析的读数，因此更改后要**重新运行批量分析**。

> **随附的胶片矩阵推导自已发布的规格表，并非实测**，这就是它们都标有 *(approx)* 的原因。它们只描述胶片的**染料本身**，因此只有在你的采集能干净读取每种染料时，它们才是完整的答案：**窄带扫描仪**（Coolscan 的单色传感器每次读取一个 LED，完全干净；Pakon 的三线阵列接近，但有轻微残余渗漏）、**三色**采集，或已应用**单次窄带校准**的单次窄带装置（见上文）。在宽带光源加拜耳传感器下，采集会叠加它自身的混合，而仅描述染料的矩阵无法涵盖它。它可能仍有帮助，但请把这些数字当作起点，而不是针对你设备的校正。

**值得尝试。** 如果某种胶片或某个光源给你带来麻烦，打开矩阵编辑器，微调六个非对角项，并把结果保存为你自己的配置文件。用那个*组合*来命名它，“Gold 200 + Spectracolor”，而不只是胶片名。你在自己设备上调校出的配置文件胜过任何数据表，而有效的配置文件值得[回馈贡献](CROSSTALK.md#贡献矩阵)，因为没有人能替你猜出你的光源和传感器。

**光源：**

*   **色相微调**（-30° 到 30°，默认 0）：把每个色相旋转一个固定角度，以抵消异常扫描光源强加的旋转。窄带 LED 和特殊荧光粉面板在偏离胶片预期的位置采样染料，这会把*每一种*颜色转过大致相同的角度，因此黄色读起来偏橙、绿色偏橄榄，而中性色不受影响。这就是白平衡无法修复它的原因：误差是旋转，不是偏色，因此没有灰可供校正。请以你已知颜色的主体（树叶、晴朗的蓝天、皮肤）来判断它，普通宽带光源下保持 0。该设置会**保留**，因为光源是你设备的属性，所以它会沿用到下一个文件，直到你更改它。中性色不受触碰，因此它绝不会干扰**归一化**中的色彩平衡裁剪。

### 4.2 去马赛克：把传感器马赛克变成像素

彩色传感器在马赛克滤镜后面每个感光点记录一种颜色，再由一种算法补出另外两种。你选哪一种，决定结果看起来有多锐利，以及它如何对待胶片颗粒。预览和导出分别选择，且两者都会保留。

仅限拜耳和 X-Trans RAW：扫描仪 TIFF、Pakon 扫描或线性 DNG 到手时已经去过马赛克。列表中只有你的 LibRaw 构建编译进去的那些算法。

*   **预览** / **导出**（两者默认都是 **Auto**）：*Auto* 保持 NegPy 自己的选择，屏幕上是快速的半尺寸解码，导出用 AHD。对预览而言，Auto 和 Linear 最快；其余的以全尺寸解码。**AHD** 是 LibRaw 平衡的默认值，**VNG** 偏平滑，**PPG** 快速且边缘干净，**DCB** 和 **DHT** 追逐精细细节，**AAHD** 柔化边缘以抑制伪影。

### 4.3 归一化：底片 → 正像

底片如何被测量并归一化为正像。决定运行*哪一种*转换的胶片模式位于面板上方（§4），而扫描如何解码则在**校准**中（§4.1）。

*   **多核 CPU 渲染**（**偏好设置 → 性能**，位于 **GPU 加速** 旁边）：把 CPU 渲染内核分散到你的各个核心上。它立即生效，无需重新编译，也无需重启。

    对收益要有现实预期。内核运行快得多，但一次合并主要由解码 RAW 文件主导，而这并不触及解码，因此整个操作只缩短了约十分之一。普通编辑的变化更小，因为 GPU 已经承担了流水线。凡是由 CPU 干活的地方收益最大：合并、导出，以及任何没有可用 GPU 的机器。

    在 Windows 和 Linux 上它是**开**的。在 macOS 上它是**关**的，有待更多证据：底层线程层在两个线程同时进入时会直接终止进程，虽然 NegPy 把每一个这样的调用都串行化在一把锁后面，但这只在一台 Mac 上得到验证，而非在整批 Mac 上。如果你打开它而应用曾经无警告地关闭，NegPy 会在下次启动时注意到，并提议把它关回去；那就是可以预期的故障，而且是可恢复的。在 `override.toml` 的 `[performance]` 下设置 `cpu_parallel` 仍然优先于偏好设置，用于一台无法启动的机器。

**分析窗口**，NegPy 在此测量黑点和白点。滑块占据该行的一半，三个按钮占据另一半：

*   **分析缓冲区**（0.0 到 0.25）：把测量窗口从帧边缘向内收，使片边、齿孔和扫描仪边框不会歪曲检测。在边框较宽的扫描上调高它。
*   **分析区域**（方框绘制工具）：在画布上手绘一个区域，*精确*对该区域测光，覆盖缓冲区。在区域内双击确认；✕ 按钮清除它。
*   **锁定边界**（挂锁图标）：冻结该帧已分析的归一化边界，使裁剪或移动滑块不再重新分析它。当你对边界满意后就锁定它。

**归一化微调：**

*   **明度范围裁剪**（-100 到 100）：设定色调范围（即黑点/白点跨度）的力度。中性档已经应用了一个小的稳健裁剪。正值收紧它，这对厚或灰雾的底片有利——那里少数离群像素会把边界推向极端。负值把边界向*外*推，用于提升黑位且不裁剪高光。
*   **色彩裁剪**（-100 到 100）：逐通道的色彩平衡裁剪（去橙色罩），独立于色调范围。正值收紧通道平衡；负值在更靠近极端处采样。
*   **全局 / R / G / B** 选择器 → **白点** / **黑点**（-0.25 到 0.25）：在自动检测边界之上的手动偏移。正的白点使其变亮；正的黑点提升黑位。在 R/G/B 模式下，这些变成逐层微调：逐染料层的片基（Dmin）和 Dmax 校正，也就是扫描仪风格的逐通道色阶。该选择器在黑白负片中隐藏——那里逐层微调没有意义——在关闭归一化的正片（反转片）中也隐藏，因为它所限定的滑块会和其余归一化微调一起被隐藏。

**串扰**、**色相微调**和传感器分离都位于**校准**中（§4.1）。它们校正的是采集，而非底片到正像的转换。

> **NegPy 不随附任何正片（反转片）矩阵。** 在正片上，矩阵下拉菜单一开始是空的，并且它和强度都被禁用，直到存在一个矩阵为止。编辑器按钮保持可用，因此你可以建立自己的：按 **+**，它会为你当前所在的工艺创建。把一个标有 `process = "Transparency"` 的 `.toml` 放进你的串扰文件夹也可以（重命名前的 `process = "E-6"` 仍能载入）。它在那里的含义不同：在底片上，染料不想要的吸收是要在反转前去除的误差，因此分离会把渲染*推向*场景，但正片**就是**成品图像，你在灯箱上看到的已经包含了那些吸收，因此分离会把它*推离*正片自身的观感。在正片（反转片）中，把它当作一个颜色分离控件，而不是保真校正。**色相微调**不受影响：它校正光源，因此它对正片的应用与对底片完全一样。

**归一化**（仅正片（反转片））是在两种渲染正片方式之间的开关。

*   **开**：自动拉伸直方图以填满动态范围，按帧测光，并像底片一样透过相纸模型印出。这是一个**针对褪色或过期正片的补救工具**，它正是为此而加入的。在染料已失去范围之处，按帧把范围测回来恰恰正确，而且因为拉伸是测光得来的，同一张正片的两次曝光会收敛到相似的渲染。

    在一张按预期曝光的正片上，预期它会显得发白、去饱和。那不是算错了：正片的密度一路延伸到 Dmax，但只有它顶端约 1.5 个数量级承载画面，因此一个跨整个范围测量的拉伸会把画面挤进印相曲线的顶端，而肩部在那里把色调和颜色一起压缩。当正片需要补救时才用它，而不是把它当作起点。
*   **关**（默认）：按**拍摄原样**渲染正片。应用相机自身的色彩矩阵，色调窗口固定到解码器的白色电平，而不是从帧测量，因此一张正片打开时的观感与它在 Photoshop、Preview、Affinity 或 Darktable 中一致，一组包围曝光也保持为包围曝光，每次曝光按各自的亮度渲染。当你按想要的方式曝光了正片、只需从那里再调整时，使用此模式。

    关闭归一化后，相纸模拟没有可作用的对象，因此印相专属的控件会被隐藏（相纸配置文件、相纸白/相纸黑、自动密度、自动反差等级、分级反差、染料分离），连同上方的归一化微调一起——后者只塑造*测得*的拉伸。留下的是一条普通的传输曲线，默认状态下中性：**印相密度**（曝光）、**ISO-R 反差等级**（对比度）、**趾部** / **肩部**及其**宽度**滑块（暗部和高光的过渡）、**阴影密度** / **高光密度**（§6.2）、逐层 R/G/B 微调，以及白平衡。Lab、调色和成品照常工作。

    **在合并的包围组上，归一化会变灰**，无论合并之前开关是什么状态。合并已经决定了色调落在哪里，而**渲染曝光**挑选它以哪一次曝光打印；一个测得的拉伸会把这个选择直接又分回去，因为在该帧停止溢出的那个锚点之下，移动它什么都不改变。无论如何这两者都不该一起用，因为归一化补救的是褪色的胶片，而褪色会*压缩*包围组存在所要捕捉的密度范围。如果你需要这个拉伸，就取消合并该帧。

    如果你来自 Lightroom 的基本面板，对应关系是：**Exposure** → 印相密度（反向，越低越亮）、**Contrast** → ISO-R 反差等级（反向，180 最软）、**Shadows** → 阴影密度、**Highlights** → 高光密度，趾部和肩部塑造两端如何过渡。密度滑块采用暗房的正负号：*正值增加密度*，因此负的阴影密度才是打开暗部的那个。**Whites** 和 **Blacks** 在这里没有对应项，因为色调窗口按设计是固定的，而这正是让渲染忠实于采集的原因。

    没有相机矩阵的源（扫描仪 TIFF、JPEG）已经在工作空间中，直接透传。

    **Linear RAW** 在这里的**校准**中变灰，因为它不适用于按拍摄原样的渲染：它在没有拍摄时白平衡的情况下解码，而相机矩阵假定该白平衡存在，且乘数会被折叠回来，因此无论如何渲染都完全相同。它保持可见，因为它是一个会保留的设置，而隐藏的设置是你看不到其状态的设置。开启**归一化**后它再次可用，那种渲染是一个测得的拉伸而非传输。导出中显式指定的 Input ICC 会替换相机自身的主色旋转，而不是叠加在其之上，因为该 ICC 提供了它自己的主色。拍摄时白平衡仍照常折叠进来。

    **窄带**和**单次窄带校准**对*任何*正片（反转片）都变灰，无论是否开启归一化；见[窄带与正片](#窄带与正片)。再现一张正片的外观是一个色度学问题，而窄带照明在三个孤立波长处采样光谱，因此眼睛所积分的波段间重叠从未被测量，这也正是窄带扫描渲染得过饱和且色相旋转的同一原因。没有输入配置文件能恢复从未被采样的东西，何况随附的那个描述的是底片染料。

<!-- panel:roll -->
### 4.4 整卷分析：整卷一致的观感

对整卷测光一次并共享基线，使来自同一胶片的各帧相匹配。

*   **批量分析**：扫描每个已载入的文件并计算整卷的平均密度和色彩平衡，丢弃离群值。导入后运行一次。*（提示：如果你使用批量自动裁剪，先以**仅图像**模式运行它，使测光看到一致的裁剪。）*
*   **使用明度平均**：该帧采用整卷的色调范围；颜色仍逐帧重新推导。
*   **使用色彩平均**：该帧采用整卷的色彩平衡；色调范围仍逐帧重新推导。两者都启用可得到完全一致的整卷；两者都关闭则为逐图自动曝光。

**ROLL**，用于跨会话复用一个基线：

*   **胶卷下拉菜单** + **加载**：应用一个已保存胶卷的边界和平衡。
*   **保存**：把当前批量分析存为一个命名胶卷，当你反复拍摄同一种胶片时很有用。
*   **删除**：移除所选胶卷（它会先询问）。各帧保持它们当前的观感；只有已保存的基线消失。

<!-- panel:presets -->
### 4.5 预设

按名称保存并调回一次完整的编辑，即整个工作区。

*   **预设下拉菜单** + **加载**：把一个已保存的预设应用到当前图像。
*   **名称字段** + **保存**：把当前设置存为一个新预设。
*   **垃圾桶**：删除所选预设。

## 5. 几何选项卡

<!-- panel:geometry -->
### 5.1 几何：裁剪与拉直

帧在这里获得最终形状：印相里包含什么，以及它是否摆正。即便别处什么都不动，多数扫描件也需要在这里过一遍。

**裁剪：**

*   **比例**（默认 `Free`）：目标宽高比：`Free`、`1:1`、`3:2`、`4:3`、`5:4`、`6:7`、`7:5`、`65:24`、`16:9`、`16:10`、`11:8.5`。每种形状各有一个条目，因为裁剪工具会随你拖动自动切换到竖向或横向。在 `Free` 下裁剪工具不受约束，而自动裁剪会从它检测到的胶片画幅取得比例，因此 6x6、645、6x7 和 35mm 各自保持自己的形状。选一个比例即可改为强制每一帧都用它。
*   **检测**（十字线图标）：把比例吸附到最接近的标准值。
*   **裁剪**工具：在画布上画一个裁剪矩形。它会在已设定的裁剪上打开，包括**自动**找到的那个，因此你可以微调自动裁剪，而不必重画。一旦你手动调整过，就不会有任何东西在它之上重新检测。**重置**清除它并关闭自动裁剪。
*   **参考线**：裁剪时叠加一条构图参考线：*三分线*、*黄金分割网格*、*对角线*、*黄金三角形*、*黄金螺旋*、*构图骨架*、*对角线法*、*网格*或*关闭*。重做按钮会旋转那些有方向的参考线；螺旋有 8 个方向，三角形有 2 个。

**自动裁剪**，用于自动检测帧边缘：

*   **模式**：*仅图像*（曝光区域）或*胶片边缘*（整幅胶片，包括片边和齿孔）。
*   **裁剪偏移**（-5 到 100 px）：把检测到的边缘向内收。正值裁得更多；负值略微向外溢出，用于检测裁得过紧时。
*   **片边微调**（0 到 150%）：切入检测到的片边多深。0% 停在胶片边缘，100% 落在检测到的图像边缘，超过 100% 则咬进画面，以清除一条顽固的白边。*仅图像*模式；它同时应用于**自动**和**批量自动裁剪**。
*   **自动**：检测并裁剪这一帧。在干净的片边上效果最好。裁剪只检测一次并存储，因此导出的取景与预览一致。**模式**、**比例**、**片边微调**和方向会重新检测；**裁剪偏移**移动已存储的裁剪而不重新检测。
*   **批量自动裁剪**：把所有可见的横向帧作为一整卷分析，用高置信度的检测校准较弱的检测。其中的竖向帧不参与整卷，而是单独裁剪，与对它按**自动**相同。当整卷中没有一帧有可读的胶片边缘时（胶片填满了传感器、周围没有留下扫描仪床），则改为从每帧自己测得的边框来裁切。只有寥寥几帧、其间还夹着一个 RGB 三联组的一卷，太短而无法把边框汇总起来，因此它按比画面更亮的边缘来裁切。它在后台运行，带进度和取消。手动、胶片边缘和不确定的帧会被放过。仅限*仅图像*模式。
*   **在一个批次里混合多种扫描**：允许，但整卷才是让批量值得运行的理由。能读到自身胶片边缘的帧保留自己的裁剪，整卷只补足那一帧测不到的部分。完全找不到边缘的帧则改为从整卷定位，因此它采用整卷的宽度和倾斜。这在一整卷一致时是补救，在一批互不相关的扫描中则是风险。来自同一台相机、同一个片夹和同一画幅的帧汇总效果最好；混合画幅在每帧都能读到自身边缘时是安全的。
*   **自动裁剪何时会放过一帧**：检测器以扫描仪床的光为背景读取胶片，因此它需要床是扫描中最亮的东西。一张高光与床一样亮的正片给不了它这个条件，于是该帧返回时未被裁剪，而不是被裁到一个猜测值。曝光到齿孔的胶片，以及填满某一边超过十分之一的相邻帧，读取方式相同。手动裁剪这些帧，或使用*胶片边缘*模式再向内裁切。

**对齐：**

*   **精细旋转**（±45°）：为倾斜的扫描件自由旋转，以小于一度的步进（正值为顺时针）。在自动裁剪之后应用，使帧保持与坐标轴对齐。
*   **拉直**工具（直尺图标）：沿地平线或竖直边缘画一条线，NegPy 会旋转使其水平或垂直。
*   **俯仰**（±15%）：绕水平轴倾斜放大架，以校正会聚的竖直线，也就是因相机上仰而向后倒的建筑。正值拉伸上边缘。单位是帧的百分比，即你在放大架上会量到的值，而不是一个倾斜角：同样的倾斜在每次放大时产生的梯形失真都不同。
*   **摇摆**（±15%）：绕竖直轴的同样运动，用于会聚的水平线。一面从侧面拍的墙，或一个与胶片不正的翻拍架。正值拉伸左边缘。

    两者都会像精细旋转那样沿被压缩的边缘复制出一条楔形；把它裁掉。如果可以，先裁剪再校正，因为测光读取的是校正后的帧：在未裁剪的扫描上，一个大的校正会把片边和周围拉进测光区域，印相随之变暗。

*   **畸变校正**（-0.100 到 0.100，步进 0.001）：径向镜头畸变。正值校正桶形畸变，负值校正枕形畸变。用胶片片边作为直边参照。在俯仰和摇摆之前校正。

<!-- panel:flatfield -->
### 5.2 平场校正：让光照均匀

用一张对裸光源拍摄的参照照片，校正来自你翻拍架或扫描仪光源的不均匀照明（暗角或衰减）。

*   **配置文件**下拉菜单，旁边有 **+** 和**垃圾桶**：挑一张参照图像并把它保存为一个命名配置文件。**+** 读取参照一次，并把它的校正烘焙进配置文件，因此之后你可以移动、重命名或删除原始参照文件而不影响你的编辑。配置文件是自包含的，像传感器和串扰配置文件一样存放在 NegPy 自己的 `flatfield` 文件夹中。**垃圾桶**会先询问：烘焙好的增益图无法恢复，而每个使用该配置文件的帧都会失去它的校正。
*   **应用平场校正**：把当前激活的参照应用到这张图像，存在配置文件后即可用。

## 6. 曝光选项卡

这是印相的核心。三个面板塑造光线、颜色和对比度，这里的一切都发生在流水线的“印相”阶段。

<!-- panel:color -->
### 6.1 滤色：白平衡

颜色校时，如同放大机头上的二向色滤镜。一个**全局 / 阴影 / 高光**选择器把控件限定到整幅图像，或把它们偏向低密度或高密度色调。

*   **拾取白平衡**（吸管）：点击一个本应为中性灰的像素，NegPy 会解算 CMY 滤色，使其在所选区域中变为中性。
*   **胶卷锁定**：把每个新打开帧的色温重新对准当前目标，同时保留它自己的色调。这是一个按区域的锁定，用于在整卷中保持一致的冷暖。
*   **重置**（撤销箭头图标）：把所选区域的色温和 CMY 恢复到中性。
*   **色温**：一根从暖到冷的操纵杆，驱动该区域的品红/黄这一对；青保持不动，如同真实暗房。
*   **青 / 品红 / 黄**（-1 到 1）：三条滤色轴，青↔红、品红↔绿、黄↔蓝。
*   **去偏色**（0.0 到 1.0，**仅彩色**）：把每个颜色层对着该帧自身的灰来平衡，使中性色从深暗部到高光都保持中性。所应用的强度随该帧有多少干净的近中性色而缩放。在彩色负片上，它击败橙色罩并从约 0.5 起步。在正片（反转片）上，它从 0 起步，并校正一张褪色正片的交叉偏色，因为正片的偏色可能就是照片本身，所以要由你来索取。在黑白负片中隐藏。

    它在正片（反转片）和黑白负片中隐藏，因为渲染在那里会忽略它。它击败的是**橙色罩**，一种制造商内建到胶片里的偏色，而非画面的一部分。正片没有色罩，它的偏色*就是*照片本身，因此去解算一个中性轴会把你拍摄时的光线剥掉；黑白负片只有一层乳剂，没有可平衡的通道。对于正片的颜色，使用**色温**和上方的 CMY 滑块，或者当异常扫描光源旋转了色相时使用**色相微调**（§4.1）。
*   **彩色环围**（靶心图标，或 `Shift+F`）：把该帧印成一个 5×5 马赛克，沿品红和黄轴每次递增 2cc、直到 ±4cc，因此偏色的方向是可见的，而不是靠猜。每个色块都是它所覆盖那部分帧的真实渲染；点击一个即可采用它的滤色。这个色梯是绝对的、以中性为中心，因此从一帧印出的环围可以与下一帧比较。`Escape` 或再按一次清除它，任何编辑也会撤下它。见下文**旋转校样**。

### 6.2 色调：密度、对比度与印相曲线

相纸的响应。顶部的一个**全局 / R / G / B**选择器把多数控件限定到共享曲线（全局），或限定到逐染料层的微调，用于**交叉偏色校正**，即暗部与高光之间各不相同的偏色，单靠滤色无法修复。

**自动辅助**，默认开启。它们替你逐帧完成工作，关闭它们则让底片如实印出。

*   **自动密度**：对每帧的中间调测光并把印相亮度锚定在那里，因此厚的和平的底片都能一致地落位。
*   **自动反差等级**：部分地依据每帧带纹理的密度范围选取反差等级，因此厚底片不再印得对比过强，平底片也不再印得浑浊；随后它在需要时加硬，使最暗的带纹理色调仍能到达一个黑位（设置目标中的暗部深度），并把最亮的带纹理色调加深到恰好足以让它们不触及相纸白（高光保持）。
*   **设置目标**（滑块图标）：调校这两个辅助所瞄准的确切亮度和对比度。应用于每一帧，并在会话之间记住。

**试条**（网格图标，或 `Shift+T`）：把该帧印成一个 5×5 网格，印相密度从左到右递增、ISO-R 反差等级从上到下渐软，因此对角线像一条分级滤镜试条那样读作从亮到暗、从软到硬。两个色梯都是绝对的、以各自默认值为中心，因此你已有的设置就是其中一个色块。每个色块都是它所覆盖那部分帧的真实渲染；点击一个即可保留它。`Escape` 或再按一次清除它，任何编辑也会撤下它。

**旋转校样**：一个色块只显示帧在它自己网格槽位上的那一条，因此你想评判的部分被卡在压着它的那一级上。当任一种校样显示时，90° **旋转**按钮和 `[` / `]` 转动的是*色梯*而非图像：每按一次把厚的一端或硬的一端移到另一条边上，轴标签随之移动。图像自身的旋转不受影响，而且转动是即时的，因为印一张校样会一次性组装全部四个方向。你最终落到的方向会在本次会话余下时间里保留。

**曝光：**

*   **印相密度**（0.0 到 2.0）：整体亮度，模拟放大机曝光时间。越低越亮，越高越厚。
*   **ISO-R 反差等级**（50 到 180）：对比度，以相纸 ISO-R 值表示。R110 约相当于经典 2 号；**R 越低越硬**（对比度越高），越高越软。在 R/G/B 模式下，一个**反差等级**微调绕中间调旋转某一层的斜率。
*   **阴影密度**（±0.9 ΔD）/ **高光密度**（±0.5 ΔD）：只提亮或压暗暗部或高光分区，而不重塑曲线。以相纸黑和相纸白为界，因此一次加深不会超出印相的极限。两者范围不同，因为密度是对数的：同样的 ΔD 在相纸黑附近读起来比在相纸白附近小得多。

    这两者在**关闭归一化**的正片（反转片）中也有效，作用于相同的色调（中心按每条曲线自身刻度上的位置映射，而非按原始密度），而且在那里它们是仅有的、不牵动中间调的控件：阴影密度打开四分之一调而高光不动，反差等级和趾部则会把整个刻度一起拖动、牺牲高光。
*   **阴影反差等级** / **高光反差等级**（分级反差，±50 ISO-R）：在深暗部或高光局部旋转对比度，是分级印相的数码等价物。
*   **对比度蒙版**（±0.5，在正片（反转片）中隐藏）：用一张模糊的低对比度蒙版把底片夹起来，如同暗房用一张蒙版胶片和一个间隔片所做的那样。密度相加，因此蒙版自身的极性决定范围往哪个方向走，它的伽马决定走多远。这个值就是那个带符号的伽马。

    正值是普通的加蒙版情形：一张模糊的正像，直接从底片接触印出，因此底片薄处它厚。那会把范围压缩 (1 − gamma)，随后一个更硬的反差等级适配相纸，而模糊使精细细节不被卷进这次压缩。把它用在对你想要的反差等级而言对比过强的场景上，然后把反差等级按 R 往回降。超过约 0.4 后，一条柔和的光晕会沿强边缘出现，正如在一张加了蒙版的印相上那样。

    负值是一张与底片同极性的蒙版，底片厚处它厚，改为把范围拉伸 (1 + gamma)。大块色调扩张，而颗粒和纹理保持不动；相比之下，更硬的反差等级会把两者一起变陡。它对一个太平、斜率已触底、反差等级无能为力的底片也有效。超过约 −0.4 后高光开始溢出，分析面板的溢出行会说明这一点。

*   **蒙版间距**（2 到 6%，没有蒙版时无效）：把蒙版撑离底片的那张透明片，以帧的百分比表示。它设定高于哪个尺度才加蒙版，因此它从一个模糊半径反向读：厚只作用于大块区域、放过细节，薄则伸入细节、咬得更狠。薄还会提亮紧邻明亮物体的暗部并使其蒙上雾翳，那正是放大师会在印相上看到的蒙版线。低于最小值时，蒙版完全不再是非锐利的，而变成一次普通的对比度变化，那是反差等级的工作。4% 是一个保守的默认值。

    这两个控件只读取你的裁剪。蒙版胶片是中性的，因此没有逐层微调，两者在 R/G/B 模式下都变灰。
*   **染料分离**（0.5 到 1.5，在黑白负片中隐藏）：密度空间中的饱和度。它在正像被解码*之前*把印相的三种染料密度推开，用的是相纸自身染料串扰所用的同一个矩阵，因此它响应你所选的相纸配置文件，并在曲线已经于趾部和肩部被压缩之处自动放松，而不是把颜色强行塞进已经无颜色可给的色调。低于 1.0 时它把染料拉向中性。1.0 为关闭。把它与颜色选项卡中的**彩度**对照——后者在解码后均匀地缩放颜色。
*   **分离阻尼**（0 到 1，在黑白负片中隐藏）：决定染料分离的推力落在*哪里*，而不是自己再加一份推力。在 0 时每种颜色受到相同对待。调高它，柔和的颜色保留全部推力，而本已饱和的颜色得到相反的对待，因此一次猛推把颜色送进本没有颜色的色调，而不是把最强的颜色驱赶直至它们压平成一块。在低于 1.0 的分离下它反过来：粉彩色变灰，而鲜艳的颜色存活。它在**染料分离为 1.0 时无效**，此时滑块变灰，因为它没有自己的观感。这与把染料分离往回调不同：一个较低的值从*一切*中取走颜色，包括本就没多少颜色的色调，而调高阻尼只从本已颜色充足的颜色中取走。

**相纸响应**，即特性曲线的形状：

*   **相纸配置文件**：一个随附的暗房相纸配置文件，彩色负片中是 RA4 彩色纸，黑白负片中是色调黑白纸。它把曲线重塑为一条基线；反差等级、密度、趾部和肩部仍在其上微调。*中性*复现默认值。每种黑白纸还携带自己的 Lith 颜色路径，由 Lith 面板取用：Fomatone 的 Lith 温暖而多彩，而*中性*和 Ilford Multigrade 几乎无色。
*   **相纸白**：模拟相纸片基密度，使白色印在约 0.93 而非纯白，就像一张真实的印相。
*   **相纸黑**：显示相纸真实的、略带灰雾感的 Dmax，而不是把它补偿为纯显示黑。关闭（默认）会应用黑点补偿，使适应后的眼睛把黑读成黑。
*   **Snap**（-0.5 到 0.5）：中间调伽马，绕参照色调使 S 曲线变陡或变平，而相纸白和相纸黑保持不动。
*   **趾部**（-1 到 1）+ **趾部宽度**（0.1 到 5）：暗部向相纸黑的过渡。正的趾部提亮暗部，得到柔和的胶片趾部；负的加深它们，并在关闭相纸黑时使确切的黑可达。宽度设定这个拐点向中间调伸入多远。
*   **肩部**（-1 到 1）+ **肩部宽度**（0.1 到 5）：高光向相纸白的过渡。正值压缩高光（类似胶片）；负值延展它们并有溢出风险。

在 R/G/B 模式下，滑块变成在全局值之上、针对那层染料乳剂的逐层微调：**反差等级**（±30 ISO-R）、**趾部** / **肩部**（±1）、**趾部宽度** / **肩部宽度**（±2）、**Snap**（±0.5）和**染料分离**（±0.4）。

### 6.3 加深与减淡：局部曝光

绘制蒙版并只提亮或压暗那些区域。三种形状，每种对应一个暗房手法：

*   **绘制蒙版**（裁切的卡片）：点击放置顶点；双击、按 Enter，或点击起点附近来闭合蒙版；Esc 取消。要编辑一个已有蒙版，在列表中选中它，然后拖动一个顶点、点击一条边上的“+”来加点，或右键点击一个顶点来删除它。
*   **椭圆**（卡片上的孔洞，或一支减淡棒）：拖出一个椭圆。三个手柄：中心移动它，另外两个设定每条轴，因此它可以被拉伸和倾斜。它有固定的三个点，不能增删。
*   **卡片边缘**（渐变加深）：从获得完整曝光的边缘（实线）拖到它淡出的位置（虚线）。这是放大师把一张卡片移过相纸：一次天空加深、一个被挡回的角。两个手柄之间的间距就是柔和度，因此**羽化对这种形状不起作用**。

蒙版手柄可以移到画面之外，而一张倾斜的卡片边缘通常需要这样：它的线必须起始于越过它所加深的那个角，否则倾斜会把那个角从完整曝光的一侧切掉。拖进帧周围的灰色区域。

*   **蒙版列表**：每个蒙版显示它的形状图标和减淡（提亮）、加深（压暗）或反差等级（仅对比度），连同它携带的值。眼睛图标切换它的轮廓；垃圾桶删除它。
*   每个蒙版在画布上都被染色，使其范围可见。按住**加深**、**羽化**或**反差等级**，或拖动一个顶点，染色就会褪去，直到你松手，因此你是在画面上、而不是透过染色来评判其值。任何与你正在处理的蒙版**相交**的蒙版会随它一起褪去染色，因为叠加的染色才是最遮挡该区域的东西；与它不相交的蒙版保留各自的染色。卡片边缘覆盖帧的整条边，反相蒙版覆盖它的周围，因此两者都算作与该区域内的任何东西相交。
*   **加深**（-2 到 2 挡，默认 0）：所选蒙版的印相曝光，其符号与 NegPy 其余部分标记相纸上光线的方式一致。**正值为加深**（更长曝光、相纸更暗），**负值为减淡**（挡回、相纸更亮），方向与印相密度和成品输出的边缘加深相同。一个新画的蒙版停在 0，因此在你给它一个值之前它什么都不改变。
*   **羽化**（0.0 到 0.15）：所选蒙版的边缘柔和度，以帧短边的一个分数表示。在卡片边缘上无效。
*   **反相**：作用于所选蒙版内部*以外*的一切，因此它是卡片本身，而非从中裁切的孔洞。用一个形状加深周围、保住面孔。
*   **反差等级**（-40 到 40 R）：以所选蒙版自己的对比度印出它，以相对该帧反差等级的 ISO-R 点数表示，负值更硬。这就是暗房透过硬滤镜的加深：以 −20 R 加深天空，它变暗而旁边的高光不被压平；以 +15 R 减淡面孔，暗部打开而不发白。旋转绕该区域自身的中间调进行，因此一个加深为 0、设了反差等级的蒙版只改变对比度，不改变整体密度。重叠的蒙版把各自的反差等级相加，结果像 NegPy 中其他每个反差等级一样被钳制到 ISO-R 色梯（R50…R180）。

**打印批注**（导出选项卡，或 **Shift+N**）把该帧变成放大师标注过的工作样张。每个蒙版都被描边，并标注它的编号和以挡为单位的值；卡片边缘没有轮廓，因此它被标为帧中获得完整曝光的那条边。角上的一张卡片携带印相配方：相纸、印相密度、ISO-R 反差等级（设定了分级反差微调时连同它们）、滤色、趾部和肩部、Snap、边缘加深，以及减淡/加深列表。

有两个约定值得了解，都借自暗房而非滑块：

*   **加深画阴影线，减淡留空。** 涂色标出相纸获得*额外*曝光之处。
*   **这些数字是曝光，不是亮度**，与加深滑块使用的约定相同，因此一个 +1.00 st 的蒙版写作 `Burn +1`。数值在足够接近时落在 ⅓、½ 和 ¼ 分数上，否则印成小数。

一个带局部**反差等级**的蒙版还携带它实际印出时的反差等级，而非微调值：在一个反差等级为 R115 的帧上、−20 R 的 +1.00 st 加深写作 `Burn +1 @ R95`，而一个仅反差等级的蒙版读作 `Grade @ R95`。

每个蒙版都在这张图上，包括你用眼睛图标隐藏了轮廓的那些：那只眼睛是为了让编辑不杂乱，而一份悄悄省略了某次加深的打印记录会是错的。当试条、任一预览、前后对比基线，或裁剪和分析工具占据画布时，叠加层会让到一边。预览和它的导出都在导出选项卡的**打印批注**分区中。

### 7.1 Lab：润饰与细节

模拟一台冲印扫描仪（Frontier 或 Noritsu）自动所做的事。颜色控件在黑白负片模式下隐藏。

**颜色**（在黑白负片中隐藏）：

*   **彩度**（0.0 到 2.0）：一个在印相被解码后应用的颜色缩放，对每个色调都均匀，因此它是一个润饰手段，而非密度空间的手段。1.0 为不变，0 为灰度，2.0 为加倍。若想要一种表现得像印相的饱和度，请改用曝光选项卡中的**染料分离**。低于 1.0 是一个平直的缩放；高于 1.0 时，本会溢出显示色域的像素会得到一个朝它们自身色域内余量的柔和逐像素拐点，而不是一次生硬的逐通道钳制，因为只钳制过冲的通道会移动那个平直缩放本身所保留的色相。
*   **肤色保护**（0.0 到 1.0，默认 0.5）：把肤色系的颜色压在一个彩度上限之下，使面孔不会晒红。色相和明度不受触碰，而彩度只会被拉低、绝不增加，因此把彩度设为 0 仍给你灰度。它独立于彩度，并在彩度为 1.0 时与之协同：从印相曲线或滤色而来的过饱和皮肤同样会被勒住。较高的值降低上限：0.5 的默认值只捕捉真正过度的彩度，1.0 让皮肤变得哑光，0 为关闭。这个蒙版是暖色相*且*皮肤自身的彩度*且*中等明度三者的组合，这正是一件红外套、一场饱和的日落、砖色或秋色被排除在外的原因。它无法分开的是那些与皮肤处于相同彩度的暖色物体（裸木、棕褐色皮革、沙），它们会随之柔化。同一个界限也反过来切：真正过度到来的皮肤，比如晒伤，只会被部分捕捉，因此那要靠彩度或滤色面板来处理。
*   **彩度降噪**（0.0 到 5.0）：平滑颜色噪点，尤其在暗部，同时让明度颗粒保持原样。

**锐化：**

*   **方法**：*USM 锐化*（提升边缘对比度）或*反卷积*（Richardson-Lucy，可逆转扫描仪的光学模糊；把半径设为扫描的模糊宽度）。
*   **锐化**（0.0 到 1.0）：数量，作用于 L（明度）通道，因此没有彩色光晕。
*   **半径**（0.5 到 3.0 px）：以输出像素为单位的模糊宽度，细颗粒用小值、软扫描用大值。锐化作用于导出文件的像素，因此适应窗口的预览显示的锐化比导出的少；用放大镜在 1:1 或在 100% 缩放下评判它。
*   **蒙版**（0.0 到 1.0）：把锐化限制到边缘，从而保护天空、皮肤和颗粒等平坦区域。与它无关的是，两种方法都以三分之一的数量锐化最深的暗部，因为那里是底片颗粒最粗的地方。

**细节：**

*   **CLAHE**（0.0 到 1.0）：局部对比度，不冲爆全局高光或压死暗部。省着用，因为接近 1.0 时可能显得卡通。它在除尘之前运行，因此修复作用于最终的呈现。

**特效：**

*   **辉光**（0.0 到 1.0）：镜头泛光，明亮的高光在所有通道间散射，产生一种梦幻的柔和。
*   **光晕**（0.0 到 1.0）：光线从片基反射回来散射出的红色辉光。仅高光，以红色为主。

### 7.2 替代工艺

两种不同于常规银盐放大的印相工艺。用顶部的**无 / Lith / 蓝晒**按钮选其一，且只显示该工艺的控件。两者都仅限黑白负片，且默认关闭。

#### Lith 印相

Lith 印相是这样一种暗房工艺：对一张支持 Lith 的相纸大幅过曝，在一种非常稀释的低亚硫酸盐显影液中显影，然后在中途把它取出。你得到奶油般的暖调高光，以及一次骤然跌入坚硬、乌黑的暗部，两者之间几乎什么都没有。

这里没有颜色控件。在曝光面板中所选的相纸设定整条路径，从桃色高光经橄榄色过渡到中性黑。*中性*和 Ilford 相纸的 Lith 几乎无色；给你桃色和橄榄色的是 Fomatone。

选中 Lith 时，棕褐色、铁蓝、铜和钒在调色面板中变灰，因为它们在 Lith 印相上没有独特效果。硒和金保持可用，并在这里表现不同（见 7.3）。

*   **曝光**（0 到 5 挡，默认 2）：印相过曝。真实的 Lith 印相用比正常印相多两到四挡的光。更多光意味着更暖、更多彩的高光和更软的层次。
*   **抢救点**（0.0 到 1.0，默认 0.55）：印相在显影液中停留多久后你把它取出。较高值把暗部变黑的那个点进一步沿色调刻度上移，给出更深、更冷的黑和一条更宽的无差别暗部带。较低值让印相保持高调和温暖，黑位偏弱。
*   **骤黑度**（0.0 到 1.0，默认 0.6）：暗部变黑有多突然。高值把过渡变成一个台阶，因此往下一个分区堵死、不留任何分离。低值留下一个平缓地滚入黑色的过渡。在暗房里，这是显影液的对苯二酚与碱之比。

#### 蓝晒

蓝晒是在紫外线下接触印相到刷有铁盐的纸上。没有需要计时的显影，其中也完全没有银：影像物质是普鲁士蓝，它吸收约 700nm 的红光，因此印相绝不会变黑，而是变蓝。高光呈现绿色，那是蓝色与留在纸中的黄色感光剂混合之处。

有两点使它看起来不像一张放大照片。它只容纳一段很短的密度范围，因此一张在相纸上正常印出的底片会在两端溢出。而且它压缩中间调，因此刻度的中段比两端更平。

选中蓝晒时，每种化学调色剂在调色面板中变灰，因为没有银可供那些药浴反应。请改用漂白和单宁。分离调色仍然有效。

*   **感光剂**（Classic 或 New，默认 Classic）：*Classic (Herschel)* 是原始的柠檬酸铁铵配方。它在水洗中流失大量颜料，因此最高只到一种相当浅的蓝，并在高光留下强烈的绿色污渍。*New (Ware)* 是草酸铁配方，它在水洗中保住的颜料多得多，因此深邃、干净得多。
*   **曝光**（-2 到 4 挡，默认 0）：在紫外光源下的时间。更多光把刻度更多地推向蓝色；更少光让印相显得苍白、高调。
*   **曝光范围**（0.8 到 2.8 log D，默认 1.4）：感光剂能印出的底片密度范围，也就是对比度控件。Ware 测得传统配方约为 1.0 到 1.2，新配方为 2.4，而他的 Simple Cyanotype 有 1.8、2.3 和 2.7 的若干变体。短的范围给出对比更强、两端溢出的印相。
*   **漂白**（0.0 到 0.5，默认 0）：洗涤苏打。它把普鲁士蓝从印相中剥出，高光先来。用得够狠时，只有最深的暗部还留住任何颜料。
*   **单宁**（0.0 到 0.5，默认 0）：茶、咖啡或单宁酸。它把漂白后的铁重新显影为棕色的单宁酸铁，其覆盖力超过被它替换的颜料，因此印相变得更棕、也更深一点。先漂白可得全棕色调；单独使用单宁则呈蓝棕分裂色调。

### 7.3 调色

给印相本身上色，而非给场景上色：转化银的化学调色剂（仅黑白负片），以及一种在任何模式都有效的分裂染色。Lith 的银比正常印相的银细得多，因此调色剂在 Lith 印相上咬得更狠、也不同。开启 Lith 时，只有硒和金保持启用；开启蓝晒时全部六种变灰，因为印相中完全没有银。

**化学调色**（仅黑白负片），模拟为按所示顺序的连续调色药浴，每种强度 0.0 到 2.0：

*   **硒**：更深的黑，冷调茄色暗部。在 Lith 印相上，它沿刻度往下伸得远得多，大幅提升 Dmax，并把绿黑色暗部转为品红。
*   **棕褐色**：先暖高光；部分强度给出棕褐分裂色调。
*   **金**：在未调色的银上呈冷调蓝黑；叠加在棕褐之上时把高光转为橙红。在 Lith 印相上，它对每个密度均匀作用，而非先作用于高光，并把印相推向蓝紫。
*   **铁蓝**：普鲁士蓝暗部逐渐加深至藏青黑。
*   **铜**：从粉到砖红的偏移，伴随典型的 Dmax 损失。
*   **钒**：使中间调和高光变绿，而深暗部保持它们的黑。

**分离调色**（所有模式），一种在 Lab 空间中的叠加染色，因此颗粒和细节被保留：

*   **阴影色相**（0 到 360°）+ **阴影强度**（0.0 到 1.0）。
*   **高光色相**（0 到 360°）+ **高光强度**（0.0 到 1.0）。

### 8.1 修尘：灰尘、毛发、划痕

修点，如同当年在成品印相上用毛笔所做的那样。找到这些痕迹有三种方式（局部对比度、扫描仪的红外通道，或手动），而且它们可以叠加。无论痕迹如何被找到，修复方式都相同：其下的胶片由周围的干净胶片重建，并把该帧自身的颗粒移植回来；任何宽到无法这样处理的，则交给一个贯穿跟随结构的填充。

一个**叠加**按钮循环切换检测叠加层（关闭 → 标记 → 红外），让你看到正在被捕捉的东西：绿色是光学除尘找到的，品红色是红外的、以及被送去跟随结构填充的缺陷。

**光学除尘**依据局部对比度在可见扫描上找到斑点和毛发，无需红外：

*   打开**光学除尘**开关，然后设置**阈值**（0.01 到 1.0；越低捕捉越多，但有误报风险）和**大小**（3 到 8 px；最大斑点半径）。一个痕迹覆盖整颗斑点或整根毛发，而不只是它最暗的点。这条门槛是相对胶片自身的颗粒来衡量的，因此同一设置在任何扫描上含义相同，而且它在繁杂的图像细节内部会升高——在那里一条细暗线无法与一根毛发区分；纹理胶片上的灰尘可能需要更低的阈值，或者红外或修复工具。

**红外除尘**利用扫描仪的红外通道去除彩色染料看不见的灰尘，仅当扫描带有红外平面时才启用。

*   打开**红外除尘**开关并设置**红外阈值**（0.05 到 0.95；越低捕捉越多）。
*   **方法**选择缺陷之下的胶片如何重建。两者使用同一个红外平面和同一个阈值滑块。
    *   **NegPy**（默认）把半透明的灰尘反向除掉，用周围干净胶片的加权平均填充不透明的核心，并从最近的干净像素移植颗粒。
    *   **OpenICE** 在对数密度下工作，恢复细节而不是把它们平均掉：在每个尺度上，它加回那些在该尺度上强过红外自身对比度的画面细节，因此斑点之下的纹理得以幸存。在缺陷是实心的地方，没有细节可供恢复，于是修复改用 Digital ICE 自己的合成颗粒，在中间调最强、在刻度两端淡出。它从每一帧测量干净胶片电平与染料对红外的串扰，并把它判断为干净的胶片逐位保持原样。它在精细细节上更好、在帧的其他地方更温和，但在各种扫描仪上的验证较少，因此在你熟悉的一帧上两者都试试。
*   红外平面从 4 通道 TIFF 和 DNG（VueScan、NegPy 自己的扫描仪输出）、SilverFast 的 iSRD TIFF 和 64 位 **HDRi RAW DNG**，以及 `_IR.tif` 附属文件中读取。如果你想让文件带有红外数据，就扫成 HDRi，而不是普通的 HDR。黑白和 Kodachrome 像灰尘一样阻挡红外线，因此那些帧会被自动跳过。

**手动修复**（标题显示当前斑点计数）：

画笔标记的是一个*搜索区域*，而不是一枚印章：只有真正从周围胶片中凸显出来的像素才被重写，因此你可以在一颗斑点上大方地涂抹，而画笔内部的干净颗粒会原样保留。痕迹在两个方向上都被捕捉：印出来偏亮的灰尘，和印出来偏暗的划痕。如果画笔没有发现任何问题，它就什么都不做。

*   **修复工具**：在预览中点击灰尘斑点，把它们一个个涂掉，或拖动以涂过一连串斑点。
*   **划痕工具**：沿一条划痕或一根毛发点击若干点，然后双击或按 Enter 完成。Esc 取消，Backspace 删除最后一个点。右键点击一个叠加层即可删除它。
*   **走片划痕线**：用于胶片在穿过相机或冲扫环节时留下的长直痕迹，那些横贯整帧、通常出现在整卷每一张相同位置上的痕迹。**在划痕上任意点击一次**，整条线就被追踪并修复；无需涂抹或拖动。

    这些正是画笔最不擅长的痕迹，而且并非因为不够细心：一条走片划痕沿其长度铺开，在任何单一点上都太微弱，无法从胶片颗粒中分辨出来。线条工具一次性读取整条划痕上的证据，这才使它可见。它跟随划痕自身的角度（胶片很少与传感器完全正交），把修复加宽以匹配划痕，并且只覆盖划痕实际存在的那些段落，因此一条时隐时现的划痕在其淡出处会被放过。如果一次点击没有找到任何东西，它会如实说明，而不去碰这一帧；请直接点在线上。

    悬停会显示一条**引导线**：在你提交之前，将会被追踪的线，以及它将修复的条带。已提交的线以同样方式保持画出，因此你能看到每一条覆盖了什么；右键点击一条即可删除它。

*   **线条灵敏度**（0.05 到 0.95，在走片划痕线工具激活时显示）：一条划痕被跟随的积极程度。越低捕捉越微弱的线并修复更宽的条带；如果一条线开始把两侧的胶片也带进来，就调高它。它对已放置的线和新线都适用，因此你可以先追踪、后调校。

*   **画笔大小**（2 到 16 px）：手动画笔的直径，与屏幕上的光标一致，在修复或划痕工具激活时显示。
*   **撤销上一步** / **全部清除**：移除最近一次或全部手动修复和追踪的线；自动检测到的灰尘不受影响。右键点击一条线可只删除那一条。

### 8.2 成品输出：暗角、片夹、边框

印相如何呈现：边缘加深、锉开片夹的黑色片边，以及它周围的纸边。在流水线的最末端应用，在其他一切都定下来之后。

**暗角**（放大师的边缘加深，以挡为单位）：

*   **加深**（-2.0 到 2.0 挡）：正值压暗边缘，负值挡回并提亮。0 为关闭。
*   **大小**（0.0 到 1.0）：衰减半径。小值把它收紧在角落，大值把它铺展进画面。
*   **圆度**（0.0 到 1.0）：0 是径向的（类似镜头），1 是一个跟随印相边缘的矩形卡片加深。

**锉开片夹**，即一个被锉开的底片片夹：透明的片边印成最大黑，外框是一圈未曝光的纸边。

*   **宽度**（0.0 到 5.0 mm）：黑色片边框的厚度。0 为关闭。
*   **粗糙度**（0.0 到 1.0）：黑框靠纸一侧的边缘被锉得多么参差。靠画面一侧的边缘是相机的片门，只会轻微晃动。
*   **眩光**（0.0 到 1.0）：从锉出斜面的裸露金属上反射的光，一种辉光，它提亮锉开边缘内侧的黑，并染脏其外侧的纸。在彩色胶片上带颜色，色相沿边缘漂移，因为这束杂散光从未经过橙色罩；在黑白中则是中性的。0 为关闭。
*   **边角**（0.0 到 1.0）：孔径的角落圆角化到什么程度，因为没有锉刀能锉出锋利的内角。

纸边采用卡纸颜色，因此它与边框无缝衔接。

**边框：**

*   **宽度**（0.0 到 2.5）：边框厚度，以图像的一个分数表示。0 为无边框。
*   **底边比重**（1.0 到 2.0）：加厚底边框，以获得窗式卡纸的比例。
*   **颜色色板**：点击挑选任意边框颜色。
*   **相纸白**：用调色后的相纸白代替所选颜色为边框着色。

## 9. 收藏选项卡

把你最常用的滑杆集中到一处，于是一次例行编辑不再需要切换选项卡和滚动。在你填充之前是空的。

*   **编辑收藏**：打开一个选取器。在左侧勾选滑杆，在右侧把它们拖成你想要的顺序，然后按**应用**。
*   面板随后按你选择的顺序显示这些滑杆。它们与各自原面板中的控件是*同一*控件，因此在这里动一个就等于在那里动它，反之亦然。没有任何东西被复制，也没有任何东西被移出它自己的选项卡。
*   一个收藏项在其原控件隐藏时也随之隐藏。收藏一个滤色滑杆，当你处于黑白模式时它就消失，因为在那里它无物可作用。
*   你的选择会在会话之间记住。

## 10. 历史选项卡

两个列表：你选择保留的版本，位于每一次改动的连续记录之上。

### 工作样张

一张**工作样张**是这一帧的一个命名版本，即暗房里保留你在走向最终成品途中所做的那些印相的习惯，于是当你在判定第五次走得太远之后，可以回到第三次的尝试。

*   **保存工作样张**（**Ctrl+Shift+S**）把当前编辑以一个名字保留；NegPy 会提供*工作样张 1*、*工作样张 2*等等。覆盖一个已有名字保存时会先询问。
*   **点击**一张使其生效。这算作一次编辑，因此 **Ctrl+Z** 会把之前屏幕上的内容放回来；你不会因为查看一个旧版本而丢失自己的位置。
*   **右键点击**可**导出此版本…**、**重命名…**或**删除**。删除会先询问，而重命名为空名字会被忽略。

工作样张与历史步骤在关键之处不同：它们**绝不会被修剪，也绝不会被一次后续编辑丢弃**。撤销历史保留最近 100 步，并在你回退后再编辑时丢弃你上方的分支；工作样张两者都能挺过。这个列表只有在你保存过一张之后才出现。

它们属于这一帧，而不属于你的预设：预设是你应用到其他图像上的一种观感，工作样张是这一张印相的一个版本。两者都存放在 NegPy 的数据库中；工作样张不会写入 `.negpy` 附属文件。

### 编辑历史

一个可滚动的列表，列出每一个编辑步骤，保留最近 100 步，最新的在顶部。当前步骤以粗体显示。

*   **点击**一个步骤跳到那个状态。
*   **右键点击** → **导出此版本…**，直接导出一个过去的状态。

## 11. 导出选项卡

### 输出意图

*   **打印**（默认）：你在屏幕上看到的完整创意观感。
*   **平扫**：一个平直、中性、低对比度的母版，保留最多的色调和色彩信息，供在别处编辑（Lightroom、Darktable、Photoshop）。它跳过印相观感、特效、调色和暗角，写入一个 16 位 TIFF，或在选择了 JXL 且色彩空间可标记（sRGB、P3、Rec 2020 或 Greyscale）时写入一个无损 JPEG XL。你的应用内预览不受影响。
    *   **预览平扫**：在画布上临时显示平扫母版，而不改变你的编辑。
    *   **胶卷基线**：测量每一个可见帧并共享一个曝光基线，使平扫母版在整卷中保持一致。建议在一次平扫批量之前使用。
*   **线性**：绕过整个暗房流水线，把扫描仪或相机解码后的缓冲区转储为一个线性 16 位文件。输出格式可选：**TIFF**（默认，经 zlib 压缩，真正无标记）或 **JPEG XL**（无损）。JPEG XL 没有无标记状态，因此它出来时无论如何都声称 sRGB 原色和线性传输，而这对相机或扫描仪原生原色并不成立；如果一个不作声称的文件对你重要，就用 TIFF。一个**压缩力度**滑块（1–9，默认 7）在 JPEG XL 编码器速度与压缩之间取舍。没有归一化、曝光、色彩管理、平场或传感器校正，只有应用了无损几何变换（旋转和翻转）的原始数据。支持的源：
    *   **Pakon RAW**：默认 4× 放大倍率（14 位传感器范围缩放进 16 位）。F335 文件（16 位传感器）默认不放大。
    *   **LinearRaw DNG**：SilverFast HDRi（3 通道）和 VueScan（4 通道 RGB+IR）。红外被写为一个单独的灰度文件，带 `_ir` 后缀，采用你为主输出所选的同一格式。
    *   **Camera RAW**：以单位白平衡（1,1,1,1）去马赛克。相机的拍摄时白平衡被写入 XMP（`RAW-WB: R G B`），以便下游工具应用它。源设备和时间戳被保留。三色三联组（窄带 R/G/B 曝光）被合并为一个单独的合成 TIFF。拼接合成在组装时逐块应用平场和传感器校正，以获得干净的接缝；拼接与三联组的组合也受支持。
    *   **Coolscan NEF**：Nikon Coolscan 扫描仪文件。尽管名字如此，这些并不是原始传感器数据：其内容取决于扫描时所用的 Nikon Scan 设置，因此线性、未经处理的输出需要在扫描之前设好正确的设置。全分辨率的 RGB SubIFD 被直接读取，RGB 之外的任何额外通道都被丢弃，因为 Coolscan 没有单独的红外通道。不放大。
    *   **Flextight FFF**：Imacon/Hasselblad Flextight 扫描仪文件，包括标准的未压缩 16 位 RGB 导出和 SGI LogLuv 压缩的原始文件（`.3fr`/`.fff`）。LogLuv 文件通过一条 LogLuv → XYZ → 线性 sRGB 流水线解码，带逐通道百分位归一化；LogLuv 是 HDR，因此归一化是解码的一部分，没有它数据会被截断，而非原始。按像素数选择最大的图像 IFD。数据是线性的扫描仪透射率。来自专有 plist（标签 50457）和固件数据块（标签 46279）的内嵌 FlexColor 元数据（胶片、胶片类型、扫描日期、扫描仪序列号）被一路带到输出 TIFF 头部。不放大。
    *   **Noritsu RAW**：无头部的 BGR 16 位扫描仪转储。帧尺寸由文件大小对照已知的 Noritsu 扫描尺寸自动检测。默认 16× 放大倍率（16 位范围中的 12 位传感器数据）。
    *   **TIFF**：通用扫描仪 TIFF。如果文件有一个被标记为红外的第 4 通道（ExtraSamples = UNSPECIFIED 或缺失），它被写为一个单独的 `_ir` 文件，采用与主输出相同的格式。附属红外文件（源文件旁的 `_ir.tif`）和存放在次级 TIFF 页中的红外也会被检测到。**输入伽马**让你选择源的伽马编码（线性、1.8、2.2 或 sRGB），以便数据能在导出前被线性化。放大倍率可用，默认关闭。
    *   **放大倍率**：在写入前缩放线性数据。组合框显示适合源文件的选项：Pakon F135/F235 默认 4×，Noritsu 默认 16×，F335 和 LinearRaw DNG 默认关闭。Camera RAW、Coolscan NEF 和 Flextight FFF 没有放大倍率选项。除非你清楚为何需要更改，否则请保持默认。
    *   **应用 ICE 除尘**（在有红外通道时可见）：在写入前对线性输出应用基于红外的灰尘和划痕校正。默认关闭。
    *   **校正**（仅相机 RAW）：三个可选开关，在写入前把校正烘焙进线性输出。全部默认关闭，遵循原始转储理念。**应用白平衡**乘以拍摄时的白平衡增益；对一个三色三联组或一次单张窄带拍摄它会变灰，因为拍摄时增益对一次窄带曝光没有实际用途。**应用平场**应用平场增益校正。**应用传感器校正**应用传感器串扰解混矩阵。对拼接合成，无论这些开关如何，平场和传感器校正总是逐块应用，因为干净的接缝需要它。

    线性输出写到**目标位置**分区所指定之处，与打印或平扫导出相同：文件夹模式、子文件夹、导出路径和文件名模式全都适用。`_linear` 总是追加到渲染后的文件名上，因此写在源文件旁的转储无法覆盖那个源文件。在没有开启**覆盖**时，一个已存在的文件会使下一个变成 `_linear_2`、`_linear_3` 等等。

    线性输出像任何其他批量一样在后台运行：进度弹窗显示正在写入哪一帧，**中止**在当前帧之后停止它，完成消息会统计任何失败的帧。

    输出文件总是写得干净：没有 ICC 配置文件，没有 EXIF 色彩空间标签，没有来自源的 XMP 颜色元数据。两种格式都携带原始像素，加上来自源文件的设备元数据（Make、Model、DateTime），以及一段记录源格式、放大倍率、白平衡和所应用任何校正（包括 ICE）的描述。JPEG XL 还携带上文提到的强制颜色标签，它并非来自源文件；该格式无法不设置它。

### 导出按钮

主**导出**动作。它的箭头菜单选择范围：当前帧（Ctrl+E）、所选帧，或全部可见帧。每个范围都使用下方的设置。要在一次运行中以多于一种格式或大小交付相同的帧，使用导出预设。

### 格式 / 大小 / 色彩管理 / 目标位置

*   **格式**：`JPEG`、`TIFF`、`PNG`、`JPEG XL` 或 `WebP`，每种格式带有质量或压缩力度选项。**JPEG XL 的导出配置文件只支持 `sRGB`、`P3 D65`、`Rec 2020` 或 `Greyscale`**：它用紧凑的枚举值标记颜色，而不是内嵌一个 ICC 配置文件，而 NegPy 的 JXL 编码器无法携带任意一个，因此 `Adobe RGB`、`ProPhoto RGB` 和一个自定义输出 ICC 会被拒绝并报错。挑一个受支持的空间或换一种格式。
*   **位深**：`8-bit` 或 `16-bit`，用于 TIFF、PNG 和 JPEG XL。JPEG 和 WebP 是 8 位格式，会隐藏这一行。平扫母版总是 16 位，也会隐藏它。
*   **压缩**（TIFF）：`Uncompressed`、`LZW` 或 `ZIP`。三者都是无损；ZIP 通常体积最小。
*   **压缩**（PNG）：`0`–`9`。无论如何都是无损：越高越慢、越小。
*   **渐进式**（JPEG）：在下载时分多遍渲染图像。
*   **输入 ICC**：把源文件当作这个配置文件来处理，用于一次扫描的配置文件已知但未标记之时。它只覆盖**原色**：色调曲线始终是流水线自己的，因此一个矩阵型配置文件所声明的 TRC 被忽略（两个原色相同但 TRC 不同的配置文件渲染结果一致）；一个 LUT 型配置文件自己的输入曲线仍被尊重。
*   **导出配置文件**：导出文件被转换到并被标记的那个。要么是一个色彩空间（`Same as Source`、`sRGB`、`Adobe RGB`、`ProPhoto RGB`、`P3 D65`、`Rec 2020`，或用于真正黑白输出的 `Greyscale`），要么是为某台打印机或纸张导入的一个 ICC 配置文件。`Same as Source` 会说出它为当前打开帧解析到的空间；对一个未标记的扫描，那就是流水线所编码到的 Adobe RGB。一个导入的配置文件不是仅供预览的打样：文件会被转换到它并把它内嵌。JPEG XL 输出不可用；见上文格式说明。
*   **导入 ICC**（色彩管理标题上的文件夹按钮）：把一个 `.icc`/`.icm` 复制进 `~/NegPy/icc/`，它会同时加入两个列表，无需重启。一个以内置空间命名的配置文件（`sRGB.icc`）会在各处替换那个空间的配置文件，而不是作为一个单独选项出现，并且会先询问。
*   **屏幕打样**位于下方的**软打样**分区中，连同渲染意图和纸张模拟控件。当预览无法预测导出的颜色时，这里会出现一条警告，要么因为没有任何东西在被打样，要么因为打样瞄准的配置文件与导出所写的不同。
*   **相纸比例**：最终印相比例，或*原始*（不重设大小）。
*   **分辨率**：*原始*（完整 RAW 分辨率）、*打印*（长边**大小**以厘米计，加上 **DPI**），或*像素*（长边 **px**；短边跟随相纸比例）。每种格式都被标记一个分辨率，因此打印或排版工具会以预期的尺寸打开文件。*打印*使用你设置的 DPI，*像素*使用它自己长边所隐含的 DPI；*原始*不重采样任何东西，因此它保留源文件自己的分辨率——从其 EXIF 或文件自身的记录（如 JPEG 的 JFIF 密度）读取，并且只有在源文件不作声明时才回退到 **DPI** 字段。线性输出遵循同一规则。
*   **目标位置**：**文件名模式**（一个 Jinja2 模板，带导出设置，加上诸如胶卷、相机和胶片等元数据字段；见 [TEMPLATING.md](TEMPLATING.md)），一个**覆盖**开关，以及输出位置（源文件的子文件夹、与源文件相同，或一个带浏览按钮的绝对**导出路径**）。目标位置适用于全部三种输出意图：选中**线性**时，格式、大小和色彩管理隐藏（原始转储用不到它们），而目标位置保留。

### 可折叠分区

*   **预设**：一个导出预设的清单，每个都是一份保存下来的格式/大小/色彩管理/**目标位置**/文件名配方。**管理**编辑它们；**导出预设**一次用每个已启用的预设渲染这些帧，而且每个预设使用**它自己的**目标位置，而非上方侧栏的目标位置。
*   **附属文件**：**导出时保存**在每次导出时于每个源文件旁写入一个 `.negpy` 编辑附属文件；**导出附属文件**立即为全部可见帧写入它们，并在某个源文件夹只读时报告有多少失败。编辑也始终保留在数据库中；附属文件是可选的归档副本。
*   **接触印相**：把全部可见帧渲染成单张表。挑一个**模板**，或手动设置**单元格 / 间隔 / 边距 / 最大格数**，选一个输出**路径**，然后按**导出接触印相**。这张表是一个 JPEG，采用上方的 **JPEG 质量**和**渐进式**设置。
*   **软打样**：在屏幕上模拟印相。见下文。

### 软打样

这些控件只改变预览。导出的文件从不被打样。

一次软打样显示当某台打印机把画面放到某种纸上时它会变成什么。纸比屏幕暗、能呈现的颜色也更少，因此一次如实的打样看起来比未打样的预览更差。在房间自身的光线下评判它，并给你的眼睛片刻安定下来。

*   **预设**：一套保存下来的打印机和纸张配置。选一个会一并恢复配置文件、渲染意图和各开关，因此从光面到哑光只需一次点击。**无**是基线：打样导出所针对的任何东西，不模拟任何纸张。保存为当前配置命名，垃圾桶移除所选的那个。框中显示你的设置匹配哪个预设，一旦你改动其中一项就变空，因此它绝不会说出一个你已经改离的配置。这些与上方的**预设**分区不同，后者保存的是文件的交付配方。
*   **屏幕打样**（`Shift+P`，默认开启）：主开关。关闭时，预览是你以完整色域呈现的编辑，本分区的其余部分变灰。
*   **配置文件**：预览所经由打样的那个。它跟随**导出配置文件**，直到你在这里指定一台打印机或一种纸，因此你可以在导出一个网页 JPEG 的同时为一次打印打样。只列出已导入的 ICC 配置文件。用色彩管理标题上的文件夹按钮导入一个。
*   **渲染意图**：纸张无法呈现的颜色如何被纳入它能呈现的范围。**相对比色**把每一个可打印的颜色留在原处，并把其余的裁到纸张范围的边缘，这很准确，直到一块饱和区域被压平成一团。**感知**把整幅画面向内挤压，使颜色之间的关系得以保留，代价是移动了那些本可以印得好好的颜色。打印机配置文件为此自带一张表，因此值得在一帧饱和的画面上试试。**饱和度**偏好鲜艳胜过准确，适合图表，不适合照片。
*   **黑点补偿**（关闭）：把画面中最暗的色调缩放到纸张能呈现的最暗处，而不是把它之下的一切裁掉。
*   **模拟相纸白**（关闭）：显示纸张自身的白色，而非屏幕的白色。画面变暗并带上纸张的色调，这正是一张印相看起来比屏幕更平的主要原因。
*   **模拟墨黑**（关闭）：显示纸张真实的最深黑，而不是把它映射到屏幕的黑。暗部提起并失去层次分离，正如它们在印相中那样。
*   **色域警告**：把配置文件无法打印的每一种颜色压平成灰色，使不可打印的区域可见，而不只是被计数。分析面板的**色域**行统计同一批像素。这个标记在一小段距离内淡出，而不是停在一个硬边缘上，因此把它读作一个区域，而非一张像素蒙版。
*   **显示器**：预览所经由显示的显示器配置文件，自动检测。如果检测失败就手动设置。它是打样链的另一半。

## 12. 元数据选项卡

为**原始模拟拍摄**（相机、镜头、胶片、工艺）记录的归档元数据，以 EXIF 和内嵌 XMP 写入导出文件，因此像 Lightroom 这样的数字资产管理系统显示的是你的胶片器材，而不是扫描仪。

每种导出格式都携带它：JPEG、TIFF、PNG、JPEG XL 和 WebP。TIFF 只在 XMP 中保存拍摄位置，而 EXIF 文本是 7 位的，因此排印标点会被转写（`4×5` 写作 `4x5`）。

*   **保护原始元数据**：把源文件的 EXIF/XMP 原样复制到导出文件，不添加任何东西。开启时，下方的字段被忽略，且源的分辨率被精确复制：相同的数值、轴和单位，无论源是在 EXIF 中还是在它自己的头部中声明它，即便导出被重设了大小。一个不声明分辨率的源，在每种可以省略它的格式中都保持那样。TIFF 不能省略，因此它声明导出自己的分辨率，而不是那个被读取器报告为 1 DPI 的无单位值。
*   **在批量导出中将自定义元数据同步到所有文件**：批量导出和预设导出把这一帧的拍摄、器材和工艺值写入每一个文件，而不是各文件自己的值。

**元数据预设**：一组已保存的元数据值，存放在 `~/NegPy/presets/metadata/` 中，与设置选项卡上的编辑预设分开：

*   **预设** + **加载**：把所选预设的字段写到这一帧上。只有该预设保存的字段会改变；这一帧上的其他一切保持不变。悬停在字段上可看到该预设保存了什么的列表。
*   **管理…**：器材库，为**机身**、**镜头**、**胶片**、**工艺**、**扫描**和**预设**各设一页。一个工艺条目是一份冲洗配方（显影液、稀释比、迫冲/迫减、时间和温度）；一个扫描条目是一套数字化配置。在预设页上，**+** 把当前帧的元数据以你挑选的名字保存，**笔**图标重命名一个预设或更改它保存哪些字段，**复制**和**垃圾桶**用于复制和删除。该预设保存的字段随后可就地编辑：替换它的相机、镜头、胶片、已保存的工艺或已保存的配置，或重新输入显影液、稀释比、迫冲、时间、温度、扫描备注、胶卷或曝光。无需打开任何帧。从器材库中挑选会重新填充从它读取的一切；在一个已填充的值上打字会解除与该挑选的关联。一个已保存的拍摄日期、地点、描述字段集或标记会显示但在此不可编辑，因为它们是逐帧的决定。**备注**是自由文本。初始数据在首次启动时播入 `~/NegPy/gear/`。

器材作为一个整体行走：相机、镜头、胶片、画幅，以及从它们读取的每一个其他值。因此一个加载的预设用同一个挑选填充下方的下拉菜单和导出的 EXIF，而一个为 120 胶片建的预设不可能让这一帧声称是 35mm。挑选一款胶片无论如何都会设定画幅，因此在选了胶片之后再设定诸如 `6×7` 这样的画幅。帧号绝不会保存在预设中。

**胶片器材**（可搜索；在任意字段中输入即可筛选器材库）：

*   **相机 / 镜头 / 胶片**：从你的器材库中挑选。留空表示未设置。**清除**清空这三者。

**拍摄：**

*   **日期**：这一帧的拍摄时间。只填写你知道的部分：`1998`、`1998-07`、`1998-07-14` 或 `1998-07-14 16:30`，可带一个可选的偏移，如 `+02:00`。一个不可能的日期会使字段变红且不被保存。EXIF `DateTimeOriginal` 会补齐缺失的部分；XMP `photoshop:DateCreated` 保留截断的形式，而 `negpy:CaptureDatePrecision` 说出它。扫描文件自己的时间戳移到 `DateTimeDigitized`。
*   **地点**：拍摄位置。图钉按钮打开一张地图，用于搜索一个地名、点击一个位置或粘贴坐标，它旁边的 ✕ 清空该地点，而字段本身接受粘贴的坐标对或一个 OpenStreetMap/Google Maps 链接。坐标被写入 EXIF GPS 标签和 XMP `exif:GPS*`，地名被写入 XMP `photoshop:City`/`State`/`Country`；TIFF 只在 XMP 中携带位置，而你设定的地点会整块替换源文件的 GPS 块，而不是把你的坐标放在它的海拔或航向旁边。一个带有地理标签、但此处未设定地点的源，在导出时保留它自己的坐标，且地图以它们为中心打开。这一帧在哪里被数字化只是一个起始视图，绝不是拍摄地点。用地图的 **+** / **−** 按钮、滚轮或触控板捏合来缩放地图，并拖动来平移。打开地图会连接 OpenStreetMap；输入坐标不需要网络。

**工艺：**

*   **已保存的工艺**：从器材库中挑选一份冲洗配方，以填充显影液、稀释比、迫冲 / 迫减、时间和温度。在其中任何一个上打字会解除它的关联，因此选取器绝不会说出一个已经消失的值。
*   **格式**：`—`（未设置）、`35mm`、`120`、`4×5`、`8×10`、`110`，或带一个自由文本字段的 `其他`。
*   **显影液**和**稀释比**：显影液，例如 `D-76`，以及它的工作浓度，例如 `1+1`、`1+50` 或 `stock`。两者在 EXIF `ImageDescription` 中合并为 `D-76 1+1`；稀释比还以 `negpy:DevelopmentDilution` 进入 XMP。
*   **迫冲 / 迫减**：`迫冲 +3` … `正常` … `迫拉 -3`。
*   **时间**和**温度（°C）**：显影时间，以 `9:30` 或纯分钟数表示，以及它运行时的温度。一个无法读取的时间会使字段变红且不被保存。两者都以 `negpy:DevelopmentTime` 和 `negpy:DevelopmentTemperature` 写入 XMP，并可作为 `devtime:`（分钟）和 `temp:` 搜索。
*   **清除**：清空已保存的工艺及其填充的一切：显影液、稀释比、迫冲/迫减、时间和温度。格式保留，因为它是胶片设定的。

**扫描：**

*   **已保存的配置**：从器材库中挑选一套数字化配置，以填充扫描。在它上面打字会解除它的关联。
*   **扫描**：扫描方法或备注。EXIF `Software` 始终是 `NegPy`。
*   **清除**：清空已保存的配置和扫描备注。胶卷和帧保留，因为它们是扫描盖上的，而不是配置盖上的。
*   **胶卷 / 帧**：Scanlight 拍摄的胶卷名和帧号，在拍摄时自动盖上，可在此编辑。在导出文件名模板中作为 `{{ roll }}` 和 `{{ frame }}` 可用，设定后以 `negpy:CaptureRoll` 和 `negpy:CaptureFrame` 写入 XMP。不是胶卷分析的归一化名称。

**曝光**：可选的原始快门、光圈和 ISO。点击锁图标可编辑一个自由文本字符串，例如 `1/125s f/2.8 ISO 400`。

**元数据预览**：一个实时视图，准确显示将被嵌入的内容，按拍摄、扫描、工艺和文件分组。扫描组显示源文件自己的时间戳和坐标，因此你能看到自己正在替换什么。**描述…**打开一个清单，列出哪些字段会并入 EXIF `ImageDescription`。默认是相机、镜头、胶片和 ISO；格式、显影液、迫冲/迫减和扫描处于关闭，直到你启用它们。确认**描述…**会设定那一帧的选择，并成为其他没有自己选择的帧的粘性默认，因此整卷上最后一次确认胜出。同步元数据和同步设置也能把一帧的选择连同其余元数据一起复制。

当你设定拍摄器材时，它被写入标准 EXIF，而数字化设备被单独保存在 `negpy:Scan*` XMP 标签中。让器材保持未设置，你的扫描仪或数码单反就会改为留在 EXIF 中可见。

## 13. 扫描选项卡

把胶片直接拍摄进 NegPy。两个可折叠分区：

*   **扫描仪**：驱动一台胶片扫描仪。选择一个**后端**：**SANE**（Linux/macOS；Coolscan 及其他 SANE 设备）、**Nikon Coolscan (nkscan)**（在 Linux、Windows 和 macOS 上直接驱动 Nikon Coolscan）或 **pyOpticfilm (Plustek)**（OpticFilm 8200i SE 和 8100 V2；Windows、macOS 和 Linux）。控件按你决定它们的顺序分组：**胶片**（胶片上是什么）、**质量**（分辨率、位深、额外扫描遍数）、**构图**（哪些帧，以及窗口）和**输出**（格式、文件夹、文件名模板）。当设备在某组里没有内容时，该组的标题连同整组一起消失。**帧**以一个列表接受要扫描的帧：`1-6`、`1,2,5`，或留空表示胶片上的每一帧。胶片条预览把它的选择写到那里，因此无需再次预览就能更改选择。**扫描**上方的一行说明按下它会做什么：多少帧、以什么分辨率、哪些额外扫描遍数，以及大约占多少磁盘。**位深**仅当设备提供多于一种位深时才出现，因此对只有 16 位的 OpticFilm 8200i SE 它是隐藏的。**自动对焦**和硬件**自动曝光**仅当连接的设备报告它们时才出现，因此通常在 Coolscan 上有、在 OpticFilm 8200i SE 上没有。**预扫描**出现在支持低 DPI 全窗口预览的设备上，例如 OpticFilm 8200i SE：运行预览，拖动一个裁剪矩形，下一次扫描就使用那个硬件 ROI。当扫描仪暴露一个 `scan-exposure-time` 选项时（某些 genesys 设备如此），会出现一个**曝光**滑块；设定它以覆盖扫描仪的默认曝光时间，其值视情况以 µs、ms 或 s 显示。没有该选项的设备会隐藏这个滑块，因此一个已保存的值绝不会弄坏另一台扫描仪。

    **pyOpticfilm (Plustek)** 说明：**OpticFilm 8200i SE**（`07b3:1825`）和 **8100 V2**（`07b3:1824`）可直接扫描。其他 OpticFilm 型号可能出现在设备列表中，但在 pyopticfilm 把它们标记为就绪之前无法扫描；在 Linux 和 macOS 上，如果 SANE 后端列出了该扫描仪，就把后端切换到 **SANE**。用**预扫描**抓取一个 1200 dpi 的全窗口预览，设定一个裁剪，然后用**应用裁剪**或**扫描帧**离开。无论哪种方式，下一次扫描都在所选 DPI 下读取那个硬件 ROI，而不是一个软件裁剪。**多重曝光**（8200i SE、8100 V2；默认关闭）合并长短两次色彩扫描遍数，以获得更多高光和暗部细节；长曝光遍数逐帧选定，而且扫描比一次普通遍数耗时更长。从 pyopticfilm 1.1.2 起的扫描与 SilverFast 方向一致；如果左右方向要紧，就重新扫描较旧的文件。

    勾选**红外**后，色彩和红外在一次扫描遍数中一并返回；pyopticfilm 把红外平面对齐到色彩帧。彩色扫描在送片之前应用在本机预先测得的 ASIC 明暗不均校正，顺序与 SilverFast 相同，因此胶片条可以保持装载。该表按 DPI 缓存，因此之后的扫描只需重新上传它。

    默认的全窗口在顶部和底部包含一点片夹的金属边框；主机路径扫描会把这些近白的边缘钳制到胶片高光，使自动曝光不被带偏。如果一帧看起来仍然不对，就调高**分析缓冲区**或裁剪。自动对焦和硬件自动曝光控件保持隐藏，因为 SE 不报告那些能力。在 Windows 上，使用前用 Zadig 把设备绑定到 **WinUSB**，因为原装厂商驱动或 SilverFast 驱动会冲突。驱动是可选的 **pyopticfilm** 包：用 `uv sync --group plustek` 或 `pip install negpy[plustek]` 安装它；Windows 发行版内置它。见 [PLUSTEK_WINDOWS.md](PLUSTEK_WINDOWS.md)。

    **Nikon Coolscan (nkscan)** 说明：驱动直接与扫描仪对话，因此它不需要 SANE 后端。它测量装载的胶片，而不是数帧：**预览胶片条…**在一次遍数中读取整条胶片，找到它上面的每一帧，并从同一次遍数中切出每一个图块。图块随各帧出现而出现，而且没有预览分辨率可选。扫描前检查构图；一个测得的边界可以用**偏移**（±2.5 mm，两个方向都行，因为帧是被重新寻址而非送过）和**漂移**微调，而且因为图块出自胶片条遍数，一次微调会重新取景而无需回到扫描仪。**扫描**在未选任何东西时会扫描胶片条上的每一帧，如果还没有预览过就先测量它。要扫描一个子集，在**帧**中输入它，或在**预览胶片条…**中取消勾选某些帧。每个图块带有自己的勾选，**全选**和**无**移动整批，它们旁边的计数说明将扫描多少帧。无论哪种方式，选择都显示在**帧**中，而退片会清除它，因为这些帧及其裁剪描述的是刚出来的那段胶片。**偏移**和**漂移**在退片后仍在，因为它们登记的是输片机构，而不是某一条胶片。有四个控件仅在这个后端上出现：

    *   **ICE**：在扫描时用红外通道去除灰尘和划痕。永久性的，因为它被烘焙进文件，不同于修尘面板的 IR 修复——后者保持可编辑。仅彩色胶片：银颗粒阻挡红外线，因此一张黑白底片上的蒙版又变回了画面。**ICE** 和**红外**互相排斥，因为它们读取同一次遍数：勾选一个会取消勾选另一个。勾选**红外**以保留该平面、稍后在修尘中清理文件，勾选 **ICE** 让扫描仪现在就做。
    *   **采样数**：扫描仪对每行取平均的读取次数（1–16）。较高的设置减少暗部噪点，并按比例耗费更多时间。
    *   **超精细**：每次遍数只读一行。更慢，且没有较快的三行模式所欠主机的行对齐问题。
    *   **胶片**：胶片上是什么。彩色负片、黑白负片、正片或 Kodachrome。它决定三件事：测量胶片条时帧边界按哪个方向读取，是否提供红外和 ICE（黑白和 Kodachrome 用银和染料阻断红外线，因此蒙版回来时是画面，而不是它上面的灰尘），以及帧如何测光。彩色负片一次一个通道地测光，这在转换器之前去除橙色罩，而不是透过它量化蓝色记录；其他每一种胶片都保留它的出厂平衡，因为在那里偏色就是画面。
    *   **画幅规格**：装载胶片上的帧长（135、66、645 等等）。在片夹已经限定它时让它保持在**自动**，并为遮挡片夹中的散片设定它。它只在输片机构测量胶片以找到其帧之处出现。一个自带帧表的片夹会固定画幅规格，因此没有可选的。

    这里的每个控件都遵循设备所报告的内容。一台 LS-50 既不显示采样数也不显示超精细：无论你要求什么，它一次读取一条 CCD 行，而且它忽略对一行的重复读取，因此两者都保持隐藏，一个从另一台扫描仪保存的设置也绝不会发给它。

    驱动是可选的 **nkscan** 包（0.9 或更新），以 wheel 形式发布：如果从源码运行，用 `uv sync --group nkscan` 或 `pip install negpy[nkscan]` 安装它。在 Linux 上，USB 上的 Coolscan 需要一条针对 Nikon 的 udev 规则（厂商 `04b0`），而 FireWire/SCSI 上的需要 `sg` 内核模块。

    **SANE 扫描窗口**：在一个卷片/胶片条送片器上（会报告一个实时帧计数），**预览胶片条…**预览每一帧，设定一个逐帧窗口，并挑选要扫描哪些帧。在一个只有单个手动片夹、没有送片器的 SANE 设备上，按钮改为显示**预览…**：它只预览当前片夹位置，并让你拖动一个裁剪窗口，供下一次扫描复用（pyOpticfilm 后端的等价物是上文的**预扫描**）。无论哪种方式，这个窗口都收窄扫描仪自己的硬件扫描区域，因此真正的扫描只读取那个区域，而不是读取整帧（包括片夹边缘和胶片片边）再在事后用软件裁剪。

    一次预览会在整个遍数期间占住扫描仪，因此当一个预览运行时，一个进度条跟踪它，**取消**显示为**停止预览**，它会放弃该遍数并保留已到手的图块，而**应用**和**扫描**出口在该遍数结束前保持暗态。预览按**胶片**设置所说的方向读取：负片胶片被反转，正片和 Kodachrome 不反转。
*   **相机翻拍**：数码单反或无反的翻拍架拍摄（macOS/Linux）。它在 PC Remote 模式下通过 USB 自动连接相机。连接了一个 NegPy **Scanlight** 时，它从已保存的胶片预设拍摄窄带 R/G/B 三联组；没有时，它做一次白光曝光。一个**实时取景**窗口帮你取景和对焦。拍摄的帧落入热文件夹，并直接流入三色扫描模式。

相机翻拍需要可选的 `python-gphoto2` 依赖（`pip install gphoto2`；没有 Windows 版本）。见 [CAMERA_SCANNING.md](CAMERA_SCANNING.md)。

### 胶片条预览

每个预览对话框都以同样的方式结束：**取消**，然后是**应用**（保留构图并回到面板）和**扫描**（从这里开始扫描）。应用按钮会说出它保留什么：在胶片条上是**应用构图**，在单个片夹上是**应用窗口**，在一次预扫描之后是**应用裁剪**。

*   **裁剪**：在一个已预览的帧上拖动。角点调整大小，内部移动。每一帧保留自己的窗口，而**清除裁剪**丢弃整批。
*   **偏移**：沿胶片滑动每一帧，以避开帧间间隙。帧随它增大而实时向左移动。右侧的阴影带是超出帧边界、输片机构无法送达的胶片，因此偏移超过间隙会损失帧尾。送片器无法倒退，因此在那里它只朝一个方向走。
*   **漂移**：按帧位逐级增加（或减少）偏移，用于一条间隙沿其长度渐变的胶片条。重新预览以刷新画面。
*   **哪些帧**：每个图块带有自己的勾选；**全选**和**无**移动整批，计数说明将扫描多少帧。在一条测得的胶片条上，这些勾选和裁剪描述的是输片机构中的那段胶片，因此退片会清除它们；偏移和漂移仍在，因为它们登记的是输片机构。

## 14. 偏好设置

针对整个应用程序的设置，而不是针对某一张照片。从画布的 **⋯** 菜单 → **偏好设置…**打开，用 `Ctrl + ,`，或在 macOS 上从应用程序菜单打开。更改会随你做随生效；NegPy 在启动时读取的那些行会如此说明，并点亮一条重启提示。

### 界面

*   **界面缩放**（80% 到 120%）：缩放整个界面。重启后生效。
*   **画布背景**：四个色板（黑、深灰、中灰、白），用于图像所处的周围背景。中灰是中性的判断背景；白色读起来像一张放在看片台上的印相。
*   **沉浸式画布**：工具栏浮在图像之上，而不是位于其下方，因此这一帧获得整个画布。
*   **保持缩放**：在你切换帧时保留当前缩放，而不是重置为适应。便于用同一放大倍率检查整卷。
*   **反转滚轮缩放**：向上滚动缩小。
*   **显示滑块数值**：保持每个滑块的数值框常开，而不是悬停时才显示。
*   **自定义快捷键…**、**编辑工具栏…**和**重置面板布局**：快捷键编辑器、用于挑选哪些控件放在画布工具栏上的选取器，以及回到默认的面板大小和位置。

### 性能

*   **GPU 加速**：在 GPU 上渲染流水线。当前激活的后端在这一行下方标出。关闭时回退到 CPU 流水线，它更慢，但产生相同的图像。
*   **多核 CPU 渲染**：见 §4.3。它立即生效，无需重启。
*   **预览尺寸**（512 到 8192 px）：交互画布的长边。越高在 100% 缩放下越锐利，并按比例耗费每帧更多的显存和 CPU，因此把缓存上限和已渲染帧数相应调低。RAW 文件为预览以一半传感器尺寸解码，因此超过你扫描长边的一半就无益可图。
*   **预览缓存**和**预览缓存上限**：最近查看过的多少张照片在内存中保持解码状态，以及它们的内存上限。在内存小的机器上把两者都调低。
*   **HQ 缓冲区**：在内存中保留的全分辨率 HQ 预览缓冲区。每个都很大（一次 60 MP 扫描约为 700 MB），而保留上一帧使回退即时完成。
*   **已渲染帧**：为无需重新渲染即可向后浏览而保留的已渲染帧。
*   **GPU 纹理上限**：最大的 GPU 纹理尺寸，包括 HQ 预览加载。0 让硬件决定，但在集成 GPU 上除外——那里会自动应用一个保守的默认值，以避免显存崩溃；如果导出耗尽显卡内存，就把它设为 4096。

从**预览尺寸**往下的每一行都在启动时读取，因此更改需要重启。在 `override.toml` 中设定的值优先于这些，其所在行会变灰并如此说明。

### 会话与存储

*   **持久化设置…**：哪些编辑会沿用到你打开的下一个文件（§2）。
*   **管理数据库…**：已存储的行数和大小、清除已保存的编辑，以及你的图库根目录。

### 启动覆盖（`override.toml`）

如果 NegPy 在启动时崩溃或有渲染故障，在不碰代码的情况下强制指定后端。首次运行时，NegPy 会为你的操作系统创建一个带默认值的 `Documents/NegPy/override.toml`。编辑它并重启。上方的 `[performance]` 数值也在这里，而这个文件中的值优先于偏好设置，这正使该文件在一台无法启动的机器上可用。

| 设置 | 取值 | 效果 |
|---------|--------|--------|
| `rendering.backend` | `"auto"`、`"vulkan"`、`"dx12"`、`"metal"`、`"cpu"` | 图像处理的 GPU 后端。`"cpu"` 完全禁用 GPU。 |
| `display.qt_rhi_backend` | `"auto"`、`"vulkan"`、`"d3d12"`、`"metal"`、`"opengl"`、`"software"` | Qt UI 渲染后端。 |
| `display.qt_platform` | `"auto"`、`"xcb"`、`"wayland"` | 窗口系统插件（仅 Linux）。 |
| `performance.force_hq_preview` | `true` / `false`（或缺省） | 覆盖已保存的 HQ 预览开关。 |
| `performance.cpu_parallel` | `true` / `false`（或缺省） | 多核 CPU 渲染内核。默认开启，macOS 上除外。 |
| `logging.level` | `"debug"`、`"info"`、`"warning"`、`"error"` | 日志详细程度。报告问题时使用 `"debug"`。 |

`max_texture_size`、`preview_render_size`、`preview_cache_max_bytes`、`preview_cache_max_entries`、`preview_cache_max_full_res_entries` 和 `render_memo_max_entries` 取与它们在偏好设置中对应行相同的值。

**常见修复：**

*   **在 Linux 上立即崩溃** → `backend = "cpu"` 或 `qt_rhi_backend = "opengl"`。
*   **在 Windows 上预览黑屏或空白** → `backend = "dx12"` 或 `qt_rhi_backend = "software"`。
*   **Wayland 渲染问题** → `qt_platform = "xcb"` 以强制 X11。
*   **导出期间 GPU 内存耗尽** → `max_texture_size = 4096`。

## 15. 更新 NegPy

NegPy 在启动时向 GitHub 询问一次最新的发行版。如果有，左侧面板的徽标下方会出现一行绿色的 **⬇ 有可用更新：vX.Y.Z**。点击它以打开更新窗口，里面有发行说明、下载大小和一个按钮。

要自己检查，按左侧面板标题中版本号旁边的 **↻** 按钮。如果没有新东西，NegPy 会如此说明；如果有，按钮变成一个绿色的 **⬇**，更新窗口打开。

**安装更新**下载与*这一*副本的安装方式相匹配的构建，然后关闭 NegPy，把它安装到旧版本之上，并在新版本上重新打开。你无需手动下载、卸载或重新安装任何东西。在 NegPy 退出之前不会替换任何东西，因此一次失败的下载或一个被拒绝的权限提示会让你正在使用的安装原样保留。

各平台上会发生什么：

| 安装方式 | NegPy 获取什么 | 如何安装 |
|---------|--------------------|-----------------|
| **Windows** | `-Setup.exe` 安装程序 | 在你现有的安装之上静默运行它。Windows 会先请求管理员批准，因为该应用位于 Program Files 中。在 NegPy 关闭*之前*批准它。 |
| **macOS** | 适合你芯片（Apple silicon 或 Intel）的 `.dmg` | 挂载该镜像，并在 `NegPy.app` 包当前所在之处替换它，然后重新打开它。 |
| **Linux** | `.AppImage` | 替换你启动的那个 AppImage 文件，保持它可执行，并重新启动它。 |

你的编辑、预设、设置和图库不受影响：它们位于 `Documents/NegPy` 和本地数据库中，而不在安装文件夹里。

**当按钮改为显示“打开发行页面”时**，NegPy 无法替换自己，就把你送到 GitHub。这发生在你从源码检出运行、发行版没有适合你平台的构建，或应用被移到了某处、不再匹配其安装程序的布局时。如果容纳该应用的文件夹对你不可写（一个系统目录中的 AppImage、一个你不拥有的 `/Applications` 中的应用包），也会发生同样的情况；NegPy 会如此说明，而不是半途失败。

你可以随时用**检查更新**动作再次请求检查，它默认未绑定按键，因此在快捷键编辑器里给它一个键。

## 补充信息

*   **GPU 加速**：NegPy 用你的 GPU 实现近乎即时的预览和响应灵敏的滑块。归一化面板的分析（边界、白/黑点、归一化）在 CPU 上运行。如果你怀疑有驱动问题，就在**偏好设置 → 性能**中关闭它，或在 `override.toml` 中强制指定后端。
*   **数据库**：所有编辑都位于一个以文件哈希为键的本地 SQLite 数据库中，因此你可以移动或重命名文件而不丢失你的工作。可选的 `.negpy` 附属文件在你的源文件旁镜像编辑。
*   **保存编辑**：编辑在导出时、你切换帧时，或你显式保存时被写入数据库。在编辑途中关闭应用而没有这些动作中的任何一个，会丢失未保存的更改。

*   **流水线详解**：[PIPELINE.md](PIPELINE.md)
